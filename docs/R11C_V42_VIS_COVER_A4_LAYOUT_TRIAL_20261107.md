## 1. วัตถุประสงค์ของตัวอย่าง

ทำหน้าปก A4 แนวตั้งเพียง 1 หน้า เพื่อให้ผู้จัดตรวจการจัดภาพจริงและตัวอักษรภาษาไทยก่อนขยายเป็นภาพเปิดกีฬา/ทั้งเล่ม:

- ชื่อเรื่อง: **มิตรภาพเกมส์ 2569**
- คำอธิบาย: สูจิบัตรการแข่งขันกีฬานักเรียน กลุ่มเครือข่ายพัฒนาคุณภาพการศึกษาหนองกุ่ม
- สถานที่: สนามหลัก โรงเรียนบ้านหนองกระทุ่ม
- วันแข่งขันจากข้อมูลที่ยืนยัน: **16–20 พฤศจิกายน 2569**; เปตองนอกรอบ **12–13 พฤศจิกายน 2569** (แยกเป็นบรรทัดรอง)
- ติดสถานะ **“ตัวอย่างการจัดหน้า · ยังไม่ใช่สูจิบัตรประกาศใช้”** ให้มองเห็นเสมอ
- ไม่มีข้อความว่าภาพเป็นภาพการแข่งขันครั้งนี้ หากยังไม่มีหลักฐานยืนยัน

## 2. เลย์เอาต์หน้าปกที่เสนอ (A4 portrait)

ใช้ระบบ **EDITORIAL / HUMAN-CENTERED SPORTS** เหมาะกับภาพหมู่ครูกับเด็กในสนาม:

1. **Top masthead (~30%)** พื้นสี navy #153451, small kicker “YOUTH SPORTS / NONGKUM”, ชื่อ `มิตรภาพเกมส์` ขนาดใหญ่สีขาว และปี `2569` สีทอง #E8BC52 พร้อมเส้นทองสั้น
2. **Hero photo (~43%)** ภาพแนวนอนจาก Drive วางเต็มความกว้างด้วย crop แบบรักษาใบหน้า/ตัวบุคคล (เลี่ยง crop ศีรษะ/มือ/กลุ่มเด็ก); ภาพเป็นชั้นที่แสดงต้นฉบับ ไม่ AI แก้บุคคล
3. **Bottom editorial strip (~27%)** คำอธิบายผู้จัด วัน/สนาม + microline เปตองนอกรอบ; พื้นขาว/กรมท่าแบ่งตาม contrast; มีกราฟิกสนามเส้นบาง ไม่ทับข้อความ
4. **Footer/provenance** ระบุว่าร่าง/ภาพประกอบจากคลังภาพงานโรงเรียนที่ยังต้องตรวจสิทธิ์ ไม่กล่าวว่าเป็นภาพจากมิตรภาพเกมส์ 2569
5. **Safe area** ตัวอักษรสำคัญห่างขอบ 12–18 mm, ไฟล์พิมพ์ A4 210×297 mm; หากมี bleed สำหรับโรงพิมพ์ให้จัดในขั้น final เท่านั้น

ข้อควรระวังจากภาพจริง: ภาพกว้าง 16:9 มีผู้ใหญ่และนักเรียนหลายคนบนสนาม; หากบังคับ crop เป็น A4 full-page จะตัดตัวบุคคลที่ขอบ จึงเสนอ **hero frame แนวนอนกลางหน้า** แทนปก full-bleed ทั้งหน้า

## 3. ตัวอักษรและภาพ

- ข้อความภาษาไทยต้องเป็น **PDF text layer** ที่ค้นหาได้ ไม่ให้ AI พิมพ์ตัวไทยลงรูป; ใช้ฟอนต์ไทยที่ฝังใน PDF และตรวจคำ `มิตรภาพเกมส์` `หนองกุ่ม` `พฤศจิกายน`
- หัวเรื่อง: ตัวหนากลุ่ม Noto Sans Thai/Google Sans (ภาษาไทย) ที่ทำงานได้จริง; เนื้อหาใช้ฟอนต์ไทยอ่านง่าย; ส่วนประกาศราชการยังคง **Sarabun ฉบับเต็ม** เดิม
- ห้ามสร้างตราทางการ/ตราโรงเรียน/โลโก้/เลขคู่/คะแนน/รายชื่อเด็กหรือคำสั่งใหม่; ไม่มีการแต่งรูปที่ทำให้เข้าใจว่าบุคคลอยู่ในการแข่งขัน 2569
- ภาพจริงเป็น **preview-use only** จนตรวจแหล่งที่มา สิทธิ์ของผู้ถ่าย และความยินยอม/ฐานสิทธิ์การเผยแพร่ภาพบุคคล (โดยเฉพาะเด็ก) สำหรับสิ่งพิมพ์และการแชร์สาธารณะ
- หากยังไม่ผ่านสิทธิ์เผยแพร่ ให้คงไฟล์ตัวอย่างเป็นการตรวจภายใน; หน้าปกทางการต้องใช้ภาพที่ตรวจสิทธิ์แล้วหรือภาพกราฟิกที่ไม่ระบุตัวเด็ก

## 4. เกณฑ์รับรองตัวอย่างก่อนต่อเข้าระบบจริง

- PDF **1 หน้า A4 portrait** + PNG preview; ตรวจ render อย่างน้อย 150–200 dpi และดูข้อความทุกส่วน
- ไม่ crop ใบหน้า/ศีรษะผิดพลาด; รูปคมชัดเมื่อพิมพ์ A4 ตามต้นทางจริง; ไม่ยืดภาพผิดสัดส่วน
- ข้อความครบ ถูกต้อง ตรวจค้นหาจาก PDF text layer ได้; ไม่มีสระ/วรรณยุกต์เสียหาย
- มีสถานะ **ตัวอย่าง / ไม่ใช่ฉบับเผยแพร่** ชัด
- ไม่ใส่เนื้อหาภายในเล่ม, ไม่แก้เนื้อหาทางการ/รายการแข่งขัน, ไม่แตะ builder main, ไม่ merge ไฟล์ภาพเด็ก/PDF preview เข้า repo สาธารณะ
- ทดสอบ 100% และบนมือถือ/iPhone อีกครั้งก่อนอนุมัติใช้งานใน builder
- หลังผู้จัดอนุมัติภาพและลิขสิทธิ์ จึงเพิ่ม public-safe asset manifest และ slot `cover.hero` ในตัวสร้างเดิมผ่าน PR แยก; ไม่ใช้ Google Drive URL สดภายใน PDF
