# R15-B/C — รับรองลำดับตัดสินฟุตบอลด้วยใบแดงก่อนใบเหลือง (6 พฤศจิกายน 2569)

**บันทึกการตัดสินใจจากผู้จัดก่อนแก้โค้ด** ต่อจาก PR #49 (H2H GD) และ #51 (เก็บจำนวนใบเหลือง/แดง); ผู้จัดตอบรับตัวเลือก “ทีมที่มีใบแดงน้อยกว่าอยู่เหนือก่อน แล้วจึงดูใบเหลือง” วันที่ 6 พ.ย. 2569

## ลำดับที่รับรองสำหรับฟุตบอลรอบลีก 12 ปีชาย
1. **คะแนนรวม**: ชนะ 3, เสมอ 1, แพ้ 0; คะแนนมากกว่าอยู่สูงกว่า
2. **เมื่อคะแนนเท่ากัน**: ผลต่างประตูได้–เสียจากการพบกันเอง (H2H GD): ถ้า 3 ทีมขึ้นไป ใช้ mini-table ของทีมคะแนนเท่ากัน
3. **เมื่อ H2H GD ยังเท่ากัน**: **ใบแดงน้อยกว่าอยู่สูงกว่า**
4. **หากใบแดงเท่ากัน**: **ใบเหลืองน้อยกว่าอยู่สูงกว่า**
5. **หากทั้งหมดยังเท่ากัน**: ไม่มีเกณฑ์เพิ่มเติมที่รับรอง → `position=null` รอผู้จัดตัดสิน (ห้ามใช้ผลต่างประตูรวม/ประตูได้/เรียงตัวอักษรให้เป็นอันดับทางการ)

## ขอบเขตข้อมูลบัตรและความปลอดภัยของอันดับ
- ใช้ยอดใบแดงและใบเหลือง **รวมเฉพาะผลที่กรรมการรับรองของ 15 คู่ลีก** ตามโครงสร้างเดิมที่บันทึกตั้งแต่ PR #51 ไม่รวมรอบรองหรือรอบชิง
- บัตร `disciplinary_cards.team_a/team_b.red/yellow` ต้องเป็นตัวเลขจำนวนเต็มไม่ติดลบ และต้องระบุ **0 จริง**; ขาดข้อมูลห้ามแทนเป็น 0
- **ไม่คำนวณบัตร 2 เหลืองเป็นใบแดงเอง**; เก็บจำนวนรวมที่ผู้รับรองระบุไว้ตามแยกสี (รูปแบบ/การตีความทางวินัยของใบแดงจากสองเหลืองนอกเหนือข้อมูลยอดที่ได้รับยังรอคณะกรรมการ)
- แม้ H2H GD ของกลุ่มแข่งกันครบ หากลีกยังไม่ครบ **ไม่ใช้ยอดบัตรชั่วคราวตัดอันดับ**; รอผลครบ 15 คู่ เพื่อป้องกันบัตรจากนัดที่เหลือเปลี่ยนลำดับ
- ในระหว่างลีก อันดับที่แยกได้ด้วยคะแนน/H2H เป็นเพียง `provisional`, ไม่ใช่ผลสุดท้าย
- ยังไม่ปลดกติกาการเข้ารอบรอง (ข้อมูล V2 กับ Google Doc ขัดกัน), การไม่มาแข่ง/ฟาล์ว, เหตุการณ์ผลทับซ้อน, เปตองจำนวนเซ็ต หรืออันดับรวมถ้วย; `football_league.approval_status` และ `sport_policies.football.status` คง pending เช่นเดิม

## Acceptance tests (ข้อมูลสมมติเท่านั้น)
- ลีก 15 คู่ 0-0 ทั้งหมด (ทุกทีมคะแนน/H2H GD เท่ากัน) แต่มีใบแดงต่างกัน → ใบแดงน้อยกว่าอยู่สูงกว่า **แม้ใบเหลืองมากกว่า**
- ใบแดงเท่ากันแล้ว ใช้ใบเหลืองน้อยกว่าตัดสิน
- แดงและเหลืองเท่ากันทั้งคู่ → `position=null`, `tied=true`
- มีผลลีกไม่ครบ → คง `position=null` สำหรับกลุ่มที่ต้องใช้ใบแดง/เหลือง
- ห้ามนับผลรอบรอง/ชิงในบัตรรวม, ห้ามอนุมาน missing cards เป็นศูนย์
- ต้องผ่าน CI R15-B/C, R15-A, R15-D/E, R14 และ Validate Draft ก่อน Merge

## การตรวจรับ
ที่มา: คำยืนยันผู้จัดในการสนทนา วันที่ 6 พ.ย. 2569 “ใช่แล้ว” ตอบคำถาม “ใบแดงน้อยกว่าก่อน แล้วจึงใบเหลืองน้อยกว่า หรือใช้คะแนนถ่วงน้ำหนัก” → เลือก **ใบแดงก่อนใบเหลือง ไม่ใช้ถ่วงน้ำหนัก**
