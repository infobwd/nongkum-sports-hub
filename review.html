พบข้อมูลผิด แจ้งแก้อย่างไร?

เปิดรายการที่ผิดแล้วกด คัดลอกข้อมูลแจ้งแก้ไข จากนั้นนำข้อความไปวางในแชทกับผู้จัด พร้อมระบุค่าที่ถูกต้องและหลักฐานที่ยืนยันได้ ระบบนี้ไม่มีการกดรับรองและไม่ส่งข้อมูลอัตโนมัติ

เมื่อคณะกรรมการยืนยันแล้ว ผู้ดูแลจะปรับ JSON ผ่าน GitHub โดยเก็บประวัติการแก้ไข และจึงจัดทำฉบับเผยแพร่ในขั้น R11E
