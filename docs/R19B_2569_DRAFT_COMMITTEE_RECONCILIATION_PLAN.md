## ขั้นตอนตามหลักฐาน
1. ถอดชื่อและหน้าที่จาก **PDF 6–16** โดยรักษาหมายเลขข้อ, หมวด, ชนิดกีฬา, ตำแหน่ง, โรงเรียน, เลขหน้า และ raw_text เพื่อให้อ้างกลับมาตรวจซ้ำได้
2. แยกคนจากรายการอ้างกลุ่ม/หน่วยงานที่ไม่ใช่บุคคล เช่น คณะกรรมการภายนอก/ตำรวจ/อปพร. และบันทึกช่องที่ยังว่าง
3. ตรวจชื่อตามตัวสะกด, รายชื่อข้ามฝ่าย, ข้อซ้ำ, หัวข้อ 14.6 ซ้ำ (เทเบิลเทนนิส vs ชักเย่อ), และตำแหน่งสนามที่ยังเป็นชื่อโรงเรียนเก่า; ห้ามอนุมานว่าชื่อคล้ายกันเป็นคนเดียวกัน
4. สร้าง **JSON ฉบับตรวจทานในเครื่อง/พื้นที่จำกัดสิทธิ์**: ไม่ Commit ชื่อหรือส่วนติดต่อใน public GitHub Repo รวมถึงไม่ใส่ใน diff, PR หรือ test fixtures
5. อาจเพิ่มเฉพาะสถิติและสถานะการตรวจจากร่างลง public JSON ภายใต้ `draft_source_review`; ให้ UI แสดงคำว่า “พบชื่อในร่างคำสั่ง” โดยไม่แสดงชื่อคนและไม่เพิ่ม `committee_approved`
6. ชื่อบุคคลจะเข้าเว็บสาธารณะเมื่อมีคำสั่งปี 2569 ที่รับรองแล้ว มีขอบเขตการเผยแพร่ที่เหมาะสม และผ่าน R19-D publication gate
