# R19-F/UX-5 — ตำแหน่งข้อความอัปเดตข้อมูลล่าสุด

วันที่ 6 พฤศจิกายน 2569

## ปัญหา
Toast รีเฟรชถูกยกสูงตามปุ่มขึ้นบนเก่าและบังปุ่มตรวจยืนยันรายชื่อบน iPhone

## ขอบเขต
แก้เฉพาะ CSS ตำแหน่ง/ขนาด/การรับสัมผัสของ Toast, JavaScript ระยะเวลาแสดงและปรับตำแหน่งเมื่อปุ่มขึ้นบนปรากฏ, version query ใน committee.html; ไม่แตะ data loader, รายชื่อ, ผล, ตารางคะแนน หรือหน้าที่กรรมการ

## พฤติกรรม
Toast แสดงราว 2 วินาที, pointer-events:none, วางต่ำ 20px+safe-area; เมื่อปุ่มขึ้นบนแสดงอยู่ให้เลื่อน toast ไปด้านซ้ายของปุ่มบนหน้าจอที่กว้างพอ ไม่ซ้อนทับ; จอแคบให้วางเหนือปุ่มแทน
