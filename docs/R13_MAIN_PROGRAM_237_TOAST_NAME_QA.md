# R13 — ตารางแข่งขันใช้สูจิบัตร PDF ล่าสุด 237 รายการ

## ข้อตกลง
- `index.html` และ `forms/score-sheet.html` อ่านข้อมูลจาก `data/program-from-pdf-2569-20261104-draft.json` ขณะ `data/draft-schedule.json` ยังเก็บหลักฐานเดิม 236 รายการ
- วัน เวลา สนามนำมาแสดงตามสูจิบัตรทันที พร้อมระบุ "ตาม PDF" เพื่อไม่ให้เข้าใจว่าเป็นประกาศทางการ
- 70 รายการที่มี QA flags แสดงคำเตือนเฉพาะรายการ
- 3 รายการที่ PDF พิมพ์ปี พ.ศ. 2568 แสดงตามต้นฉบับพร้อมคำเตือน ไม่คาดเดาแก้เป็น 2569
- 24 รายการเปตองที่ยืนยันวัน/สถานที่ใช้ป้ายยืนยันเฉพาะสองข้อมูลนั้น ส่วนเวลาเป็นเวลาตาม PDF ยังไม่รับรอง
- ข้อมูลผลการแข่งขันใช้ approved-only เหมือนเดิม ไม่แตะระบบประกาศผล
- แบ่งปันลิงก์ /r/ สำหรับ PDF ล่าสุด โดย /m/ เดิมยังคงเส้นทางและรหัสลิงก์เก่าไว้
- Toast ของปุ่มแชร์อยู่เหนือแถบเมนูด้านล่างบน iPhone; ไม่สร้างแถบถาวรปิดสถานะของ iPhone
- ชื่อบนหน้าจอและหน้าแชร์เป็น **มิตรภาพเกมส์** แต่ไม่แก้ fixture ID, ชื่อ PDF ต้นฉบับหรือ URL

## เกณฑ์ตรวจรับหลังเผยแพร่ Pages
1. หน้าเว็บหลักแสดง 237 รายการ (187 คู่แข่งขัน + 50 กรีฑา) และกรองตามโรงเรียน/กีฬาได้
2. ฟุตบอล 12 ปี ชาย คู่ที่ 2: หนองกุ่ม พบ หนองกระทุ่ม, 17 พ.ย. 2569, 08:30 น., สนาม 2 (ตาม PDF)
3. เปิดรายการที่มี QA และปี 2568 พบคำเตือนเฉพาะ ไม่รับรองอัตโนมัติ
4. รายการที่เพิ่มใหม่เปิดใบบันทึกผล A4 ได้ ตรวจสอบ PDF หน้า รหัสรายการและเวลาต้นฉบับ
5. ทดสอบปุ่มแชร์ iPhone/LINE/Android/คอม พร้อม Toast ที่อยู่เหนือแถบเมนู
6. Preview LINE แสดงชื่อมิตรภาพเกมส์และคู่ที่เลือก โดยเปิดตรงรายการได้ทั้งลิงก์เดิมและล่าสุด
7. ตรวจผลการแข่งขันคง approved-only และตรวจด้วยตาว่าขณะเลื่อนหน้า Safari ไม่มีแถบปิดบังเนื้อหาหรือ Dynamic Island

**ไม่มีการอนุมัติวัน เวลา สนาม หรือผลการแข่งขันโดยการ Merge**
