# R14 — ตารางแข่งพร้อมใช้งานและแชร์ LINE

## สิ่งที่เปลี่ยน
- หน้าตารางแสดงวัน เวลา สนามทันทีโดยไม่ซ้ำข้อความ “ตาม PDF” และใช้ปฏิทิน SVG ที่ไม่มีวันที่ JUL 17
- PDF Viewer เดิมเปิดตรงหน้าได้ผ่าน page=N และย้อนกลับไปคู่เดิมบนตารางด้วย from=program&fixture=ID โดยทางเข้า Review ไม่เปลี่ยน
- LINE ส่งข้อความพร้อมใช้ กีฬา รุ่น คู่แข่งขัน วัน เวลา สนาม และหน้าสูจิบัตร พร้อมลิงก์สั้นที่มีเวอร์ชัน ?v=14
- Open Graph เฉพาะรายการ 237 หน้าแสดงคู่แข่งขันและกลับไปตาราง ไม่เปลี่ยนรหัส fixture หรือเส้นทางเดิม
- ยังรักษาข้อมูลระหว่างเตรียมงานบนหน้าหลัก และไม่อ้างว่าผู้จัดรับรองแล้ว
- วันผิดปกติ 3 รายการใช้คำว่ารอยืนยัน ไม่เติมปีจากการคาดเดา
- iPhone ใช้ header จริงแบบ sticky มีพื้นหลังและรองรับ Safe Area โดยไม่ใช้ fixed pseudo-mask บังหน้า

## ตรวจรับหลัง GitHub Pages Deploy
1. ฟุตบอลคู่ 6 หนองกุ่ม พบ วังด้ง 17 พ.ย. 2569 13:00 น. สนาม 2 ไม่มี JUL 17 และไม่มี “ตาม PDF”
2. เปิดดู PDF หน้า 7 จากการ์ด แล้วกลับมาที่คู่ 6; เปิดจากหน้า Review แล้วย้อน Review ได้
3. LINE preview คู่เฉพาะรายการที่แชร์และมีข้อความพร้อมส่งทันที โดยไม่มีการลบประโยคเอง
4. ทดสอบ Toast เหนือเมนูล่างและการเลื่อนบน iPhone Safari/PWA/LINE in-app browser
5. ตรวจ 70 QA flags, 3 ปีผิดปกติ, ความตรงกันกับ PDF, PDF.js fallback และ Approved-only results
6. ตรวจลิงก์เดิม /m/ 236 รายการ, /r/ 237 รายการ, ใบจดคะแนนและเมนูล่าง

หมายเหตุ: GitHub Pages เข้าถึงสาธารณะได้ ข้อมูลจึงยังคงมีคำเตือนสถานะการเตรียมงานจนกว่าผู้จัดรับรอง
