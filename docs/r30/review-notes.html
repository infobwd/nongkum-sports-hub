ประเด็นรอตรวจและแหล่งข้อมูล

ประเด็นสําคัญจากเอกสารต้นฉบับที่ยังต้องตรวจรับ ไม่ใช่การประกาศเปลี่ยนคู่หรือผลแข่งขัน

01 · การแก้ไขหลัง PDF ต้นทาง

R25D3 เป็นเอกสารวันที่ 10 พ.ย. ก่อนการแก้ R27-C (ชื่อทีม/ฟอนต์) และ R28 (แจ้งเข้าชิงเปตอง) ซึ่งยังเป็น PR ร่าง จึงห้ามถือว่าเล่มย่อนี้เป็นฉบับปรับตามมติล่าสุดทั้งหมด

02 · ตารางและผังสาย

ข้อมูลต้นทางมีข้อสังเกตเรื่องเลขคู่ที่อ้างผู้ชนะผิดรุ่น ชื่อทีมและสายเปตอง รวมทั้งรายการตะกร้อคู่ที่ 24; ให้ยึดเอกสารที่ผู้จัดลงมติแล้วก่อนเปลี่ยนรายการ

03 · กรีฑา

ต้นฉบับมีเลขรายการ 35 และ 48 ซ้ํา และไม่ระบุเวลาเริ่มรายรายการครบทุกลู่ จึงคงเลขเดิมไว้และรอผู้จัดยืนยัน ไม่สร้างเลข 49/50 ขึ้นเอง

04 · กรรมการและคําสั่ง

หน้ารายชื่อกรรมการและประกาศฉบับยาวถูกแยกออกจากเล่มอ่านหลัก แต่ยังอยู่ใน PDF ต้นฉบับ 155 หน้า ต้องตรวจรายชื่อและใช้ฉบับที่ได้รับการรับรองก่อนมอบหมายจริง

รายการตรวจรับก่อนใช้เป็นสูจิบัตรทางการ
  1. ตรวจเทียบ 236 รายการกับ JSON / Sheets / มติผู้จัดรุ่นล่าสุด และบันทึกจุดต่างรายคู่
  2. ตรวจผัง 44 กลุ่ม ตารางคะแนนรวม และกติกาเฉพาะชนิดกีฬาโดยผู้รับผิดชอบ
  3. ทดสอบพิมพ์กระดาษ A4 และเปิด PDF บน Safari, Chrome และ LINE
  4. ยืนยันภาษาฟอนต์ ลิงก์สารบัญ หมายเลขหน้า เอกสารคําสั่ง และสิทธิ์เข้าถึงก่อนเผยแพร่
