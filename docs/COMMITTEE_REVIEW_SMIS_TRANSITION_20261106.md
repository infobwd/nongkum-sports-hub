# แผนเปลี่ยนรหัสเปิดรายชื่อกรรมการเป็น SMIS

## ข้อกำหนด
ผู้ใช้ยืนยันใช้รหัส SMIS เพียงรหัสเดียว เพื่อความสะดวก ไม่ต้องมีรหัสลับเพิ่มเติม

## ข้อเท็จจริงจากระบบ
ไฟล์ `data/committee-school-rosters-2569.encrypted.json` ใช้ AES-GCM+PBKDF2 และรหัสเดิมเป็นกุญแจถอดรหัสโดยตรง จึงไม่สามารถเปลี่ยนข้อความบนฟอร์มแล้วใช้ SMIS เปิดไฟล์เดิมได้ ต้องมีทั้งทะเบียน SMIS ที่ตรวจสอบแล้ว และข้อมูลต้นฉบับ/รหัสเดิมเพื่อสร้าง encrypted bundle ใหม่ทั้งหมด

## ระยะ A: ปรับ UX โดยไม่ทำให้เปิดข้อมูลไม่ได้
- ช่องรหัสแบบมีปุ่มแสดง/ซ่อนในช่องเดียว และข้อความสั้น
- คงคำอธิบายตรงไปตรงมาว่ารหัส SMIS จะใช้ได้เมื่อเปลี่ยนชุดข้อมูลเข้ารหัสแล้ว
- ห้ามอ้างว่า SMIS ใช้งานได้ก่อนมีชุดข้อมูลใหม่และทดสอบจริง

## ระยะ B: เปิด SMIS จริง (ยังติดเงื่อนไข)
- ยืนยัน SMIS ของทุกโรงเรียนจากทะเบียนที่เชื่อถือได้; ไม่เดาและไม่ใส่ค่ารหัสใน repo เป็นความลับ
- รับต้นฉบับ roster หรือใช้รหัสเดิมที่ได้รับอนุญาตเพื่อถอดและเข้ารหัสใหม่ตาม SMIS; ทดสอบโรงเรียนถูก/ผิดและการแยกโรงเรียน
- เนื่องจาก SMIS เป็นรหัสสาธารณะ ให้ใช้ข้อมูลนี้เพื่อการอ่าน/ตรวจร่างเท่านั้น และแจ้งว่าการส่งผ่าน LINE ต้องมีผู้จัดตรวจรับผู้ส่ง
