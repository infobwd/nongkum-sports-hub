# มิตรภาพเกม ปี 2569 — Nongkum Sports Hub

> **ข้อมูลสูจิบัตรฉบับใหม่ (4 พ.ย. 2569):** ถอดไฟล์ `สูจิบัตรกีฬา 69(1).pdf` แยกไว้ที่ [JSON รอตรวจรับ 237 รายการ](data/program-from-pdf-2569-20261104-draft.json) และ [รายงานจุดตรวจ PDF ใหม่](docs/PDF_REVISION_2569_IMPORT_NOTES.md) โดยมี 187 คู่แข่งขัน (เพิ่มฟุตบอลหญิงที่พิมพ์ซ้ำ 1 แถว), กรีฑา 50 รายการ; **เว็บยังใช้ข้อมูลเดิม 236 รายการจนกว่ากรรมการตรวจรับ** และยังไม่มีผลการแข่งขันรับรอง

พื้นที่ส่วนกลางสำหรับข้อมูลการจัดการแข่งขันกีฬา การประชุม คำสั่งคณะกรรมการ และสูจิบัตรออนไลน์บนมือถือ

- **ลิงก์เก่า** `index.html?fixture=<fixture_id>` เปิดการ์ดคู่แข่งขันนั้นทันทีเหนือกล่องค้นหา; หากรหัสไม่พบแสดงข้อความอธิบาย ไม่กลับหน้ารวมโดยไม่แจ้ง
- **ลิงก์แชร์ใหม่** ใช้รหัสสั้นภาษาอังกฤษ/ตัวเลข `m/fxxxxxxxx/` พร้อมหน้า HTML แยก **236 คู่/รายการ** สำหรับ LINE Open Graph Preview ที่ระบุกีฬา รุ่น ชื่อทีม และป้าย **ข้อมูลร่าง**
- ตัวอย่างคู่ที่ 9 ฟุตบอล 12 ปี ชาย หนองกระทุ่ม–วังด้ง: [เปิดลิงก์สั้น](https://infobwd.github.io/nongkum-sports-hub/m/f9ba2a496/)
- หน้าแชร์มีรายละเอียดคู่ทันทีและปุ่มเข้าสู่สูจิบัตรฉบับเต็ม จึงไม่พึ่งตำแหน่งเลื่อนหรือรายการ 12 คู่แรกของหน้าโปรแกรม
- **ผลการแข่งขัน** `results.html?result=<id>` จะเปิดตรงผลที่รับรองแล้วเท่านั้น; เมื่อยังไม่มีผลที่เผยแพร่จะแสดงข้อความว่าไม่พบผลรับรอง ไม่สร้างคะแนนสมมติ
- เมื่อปรับข้อมูลสูจิบัตรใหม่ ต้องสร้างหน้าแชร์ใหม่ด้วย `node scripts/share/build-match-pages.mjs` และตรวจ `--check` (CI ตรวจครบ 236 หน้า)
- [การออกแบบและตรวจรับ R8 สำหรับ LINE](docs/R8_LINE_DIRECT_LINKS_QA.md) — จำเป็นต้องทดลองแชร์/แตะลิงก์บน LINE iOS/Android จริงหลัง Deploy

## R7 — แก้แถบทับส่วนหัวและมาตรฐานฟอนต์ทั้งสองหน้า

- ลบชั้น `body::before` แบบ fixed และตัวบังส่วนหัวเมื่อเลื่อนบน Safari ที่ทำให้เกิดแถบสีเทา/ขาวคลุมข้อความ
- รวม **Safe Area บน iPhone** ไว้ใน `css/base.css` เพียงจุดเดียว โดยไม่สร้าง overlay มาบังหัวหน้า
- ใช้ `Noto Sans Thai` และขนาดหัวเรื่อง/หัวข้อ/โลโก้/กล่องค้นหา/ระยะขอบร่วมกันทั้งหน้าโปรแกรมและผลการแข่งขัน

- ย่อข้อความเวลาตรวจไฟล์ล่าสุด แต่ยังบอกว่าใช้ไฟล์ที่เผยแพร่บนเว็บไซต์ ไม่ใช่ Google Sheets สด

## R6 — เปลี่ยนหน้าโปรแกรม/ผลการแข่งขันได้ด้วยการแตะครั้งเดียว

- **มือถือ** มี Bottom Navigation ติดจอ 2 แท็บ: **ตารางแข่ง** และ **ผลแข่งขัน** (พื้นที่แตะอย่างน้อย 56px ต่อแท็บ และรองรับ Safe Area iPhone)
- **Desktop** คงเมนูด้านบน; หน้าเว็บยังเป็น `index.html` และ `results.html` ไม่เพิ่ม framework
- แท็บตอบสนองทันทีเมื่อแตะ และยังเป็นลิงก์ native ทำงานได้โดยไม่ต้องรอ JavaScript fetch; กดแท็บเดิมจะเลื่อนขึ้นบนแทนรีโหลด
- คงตัวกรอง `school`, `sport`, `level` เมื่อสลับหน้า และไม่ให้ค่าโรงเรียนเก่าปิดบังลิงก์แชร์ตรงคู่/ผล
- ไอคอนแชร์ใช้ SVG ที่สื่อความหมายชัดเจนขึ้น; การ์ดโปรแกรมแสดงไอคอนกีฬาและรุ่นแทนชื่อกีฬาซ้ำทุกการ์ด
- เพิ่มการจัดการการเลื่อนใต้แถบสถานะ iPhone และพื้นที่ท้ายหน้าไม่ให้แถบล่างบังเนื้อหา
- [แผนและรายการตรวจรับ R6](docs/R6_MOBILE_NAV_QA.md) — ยังต้องตรวจ Safari/Android ด้วยเครื่องจริงหลัง Deploy

## R5 — ป้องกันใบบันทึกผลผิดกีฬาและปรับ UX มือถือ

- เปิดใบบันทึกจากคู่แข่งขันแล้ว **ล็อกชนิดกีฬาและรหัสคู่ตามสูจิบัตร** ห้ามเปลี่ยนกีฬาโดยคงข้อมูลคู่เดิม
- หากเปิดรหัสผิดหรือข้อมูลขัดกัน ระบบป้องกันการพิมพ์; ใช้ปุ่ม **เริ่มแบบเปล่าใหม่** เพื่อล้างข้อมูลอ้างอิงทั้งหมดก่อนเลือกกีฬา
- เปตองมีตารางคะแนนเกมเฉพาะ, ฟุตบอลมีคะแนนตามช่วงพร้อมหมายเหตุการยิงจุดโทษ, ยิงจุดโทษและกรีฑามีแบบของตนเอง
- แยก **เวลาแข่งขันจริง** จากเวลาใน PDF ที่อาจยังไม่รับรอง เพื่อไม่คัดลอกเวลาอ้างอิงเป็นเวลาจริงโดยอัตโนมัติ
- ย้ายปุ่มแชร์ไปมุมบนการ์ดคู่และการ์ดผล ช่วยให้การ์ดสั้นลง; คงปุ่มแชร์แบบเข้าถึงได้ด้วยโปรแกรมอ่านหน้าจอ
- ลดคำเตือนผลว่างและข้อความรีเฟรชซ้ำบนหน้า **ผลการแข่งขัน**
- ดู [คู่มือและรายการตรวจ R5](docs/R5_SCORE_SHEET_MOBILE_QA.md) — การตรวจ A4 บนเครื่องพิมพ์จริงและ iPhone/Android ยังต้องทำก่อนใช้งานสนาม

## R4 — รีเฟรช แชร์คู่แข่งขัน/ผล และใบบันทึกผล A4

- หน้าโปรแกรมและหน้าผลมีปุ่ม **↻ รีเฟรช** และตรวจไฟล์ JSON ล่าสุดจากเว็บไซต์ทุก **5 นาทีเมื่อเปิดหน้าอยู่** พร้อมแสดงเวลาที่ตรวจข้อมูล
- รีเฟรชเฉพาะไฟล์ **ที่เผยแพร่บน GitHub Pages แล้ว** ไม่ใช่การอ่าน Google Sheets สด; ผลการแข่งขันจะขึ้นเมื่อผู้จัดอนุมัติและเผยแพร่ approved-only JSON เท่านั้น
- ปุ่ม **แชร์คู่แข่งขัน** ในการ์ดโปรแกรม ส่งลิงก์ `?fixture=<fixture_id>` เปิดตรงคู่ พร้อมป้ายร่าง/ยืนยันเฉพาะข้อมูลตามจริง
- ปุ่ม **แชร์ผลการแข่งขัน** แสดงในผล `approved` เท่านั้น ส่งลิงก์ `results.html?result=<result_id>`; ณ ตอนนี้ผลที่เผยแพร่ยังเป็น **0 รายการ**
- สำหรับกรรมการมี [**ใบบันทึกผลการแข่งขัน A4 แบบพิมพ์**](forms/score-sheet.html) เลือกกีฬาได้ 9 ชนิด (คะแนน, เซ็ต/เกม, ชนะ–แพ้, อันดับกรีฑา) และเปิดจาก `รายละเอียด` แต่ละรายการเพื่อเติมข้อมูลสูจิบัตรก่อนพิมพ์
- ใบ A4 **ไม่ส่งข้อมูลไป Google Sheets และไม่บันทึกผลในเว็บไซต์โดยอัตโนมัติ**; กรรมการต้องตรวจ ลงนาม และให้เจ้าหน้าที่นำเข้าผลที่รับรองตามขั้นตอนเดิม
- [คู่มือรีเฟรช แชร์ลิงก์ และออกแบบใบบันทึกผล](docs/UX_R4_REFRESH_SHARE_SCORE_SHEETS.md)
