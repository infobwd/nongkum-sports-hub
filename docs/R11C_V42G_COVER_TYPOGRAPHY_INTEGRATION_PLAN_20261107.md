## 2. เป้าหมาย V42-G (ดำเนินการใน PR อนาคต **หลัง** งานผังสายเสถียร)

### G1 — Sport title typography โดยไม่ต้องใช้ภาพถ่ายส่วนตัว (ทำได้ก่อนสิทธิ์ภาพ)

1. ยึดข้อความจริง **“มิตรภาพเกมส์”** และ **“2569”** ตามตัวอย่าง V2 โดยไม่เปลี่ยนคำหรือสะกด; ใช้สไตล์ **sport display / magazine masthead** น้ำหนักหนา, เส้นขอบ, เงาบาง, accent กรมท่า–ทอง; มี contrast อ่านชัดบนจอและเมื่อตีพิมพ์.
2. จัดข้อความเป็น **native PDF searchable/selectable text** (font/renderer ถูกลิขสิทธิ์ รองรับสระอำและวรรณยุกต์ไทยครบ) ไม่ rasterize คำไทยลงในภาพ; หากทำ outline/shadow ให้เป็นชั้นตกแต่งเสริม โดยยังคงตัวอักษรหลักที่ค้นหาได้.
3. ขณะรอภาพใช้ **fallback ที่ไม่มีภาพบุคคล** โดยยังปรับ typography ได้; ไม่ให้ QA บันทึกว่า Full Photo integration ผ่านเพียงเพราะหัวเรื่องสวยขึ้น.
4. พิมพ์ทดสอบ A4 หน้าเดียว: ตรวจสะกด, Unicode text extraction, การซ้อนของวรรณยุกต์/สระ, ความหนา/เส้นขอบ/เงา, ระยะปลอดภัย, ไม่ทับวันเวลา/สถานที่/ข้อความสถานะร่าง.

### G2 — Full Photo Cover V2 (ต้องรอ rights/print-quality gate)

1. รับเฉพาะไฟล์ภาพแนวตั้ง **จากพื้นที่ส่วนตัวที่เจ้าของงานอนุญาต** และมีหลักฐานสิทธิ์ของผู้ถ่าย, การใช้ภาพเด็ก/บุคคล, การเผยแพร่และการพิมพ์. ห้าม commit ภาพ/ลิงก์ Drive ส่วนตัว/โทเคน/ชื่อเด็กลง public repo.
2. ภาพตัวอย่างเดิมราว 1055×1491 px; ตรวจ **effective DPI ที่ A4 จริง**, ความคมใบหน้า, artifact การขยาย, การครอป/ยืดสัดส่วน; ขอไฟล์ละเอียดกว่าเมื่อคุณภาพไม่ถึง ไม่อ้างว่า print-ready จากขนาดภาพเพียงอย่างเดียว.
3. ต่อเข้าตัวสร้างเดิม `scripts/docs/build-v4-full.py` โดยใช้ local approved asset + public-safe manifest (asset key, checksum, provenance, review status) เท่านั้น; ถ้าไม่มีภาพ/สิทธิ์ไม่ผ่านให้ใช้ fallback พร้อมรายงานเหตุผล.
4. ไม่แตะองค์ประกอบอื่นของ Full Photo V2 (วัน 16–20 พ.ย., เปตองนอกรอบ 12–13 พ.ย., สนามหลัก โรงเรียนบ้านหนองกระทุ่ม, แถบล่าง, ป้ายร่าง) เว้นมีเหตุผลตรวจรับเป็นลายลักษณ์อักษร.
5. ไม่อ้างว่าเป็นภาพเหตุการณ์การแข่งขันปี 2569 หากต้นทางไม่ได้ยืนยัน. **อนุมัติรูปแบบ ≠ อนุมัติสิทธิ์ภาพ ≠ อนุมัติปล่อยเล่ม**.
