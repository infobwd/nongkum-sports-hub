## วิธีสร้างซ้ำ

ต้องติดตั้ง `weasyprint==68.0`, PyMuPDF และ Pillow ในระบบที่มีฟอนต์ไทย Noto Sans Thai/Waree ที่ใช้ได้ตามสิทธิ์. ดาวน์โหลด PDF ต้นฉบับจาก Google Drive แล้วรัน:

```bash
python build_compact.py source-155.pdf output/mittraphap-r30-draft.pdf
python qa_compact.py source-155.pdf output/mittraphap-r30-draft.pdf output/QA_REPORT.json
```

ไฟล์ HTML หน้าใหม่อยู่ในโฟลเดอร์ `output` และ CSS ต้นฉบับคือ `layout.css`. ส่วนหน้าแข่งขันต้นฉบับรักษารูปแบบเวกเตอร์จาก PDF ต้นทาง (ยัง **ไม่ใช่ HTML ที่แก้ไขเนื้อหาทุกตารางได้**). การแก้ข้อมูลแข่งขันต้องทำผ่านแหล่งข้อมูลที่ผู้จัดรับรองและสร้างชุดใหม่นอกเหนือจาก R30 นี้
