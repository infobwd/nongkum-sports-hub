# กีฬากลุ่มหนองกุ่ม — Nongkum Sports Hub 2569

พื้นที่ส่วนกลางสำหรับข้อมูลการจัดการแข่งขันกีฬา การประชุม คำสั่งคณะกรรมการ และสูจิบัตรออนไลน์บนมือถือ

## สถานะปัจจุบัน: P1 — นำเข้าจาก PDF ครบ แต่ยังไม่อนุมัติ

**ข้อมูลจาก PDF ทั้ง 40 หน้าได้รับการจัดหมวดและถอดโปรแกรมการแข่งขันแล้ว — ทุกแถวเป็น DRAFT ไม่ใช่ประกาศการแข่งขันทางการ**

| สิ่งที่นำเข้า | จำนวน |
|---|---:|
| โรงเรียน | 8 |
| หมวดกีฬา/กิจกรรมสำหรับค้นหา | 9 |
| รุ่น/ประเภทที่มีเลขกำกับในผัง | 33 |
| ตำแหน่งรายชื่อทีมตามผัง | 177 |
| คู่แข่งขันในโปรแกรม | **186 คู่** |
| รายการกรีฑา | **50 รายการ** |
| แถวลู่กรีฑา | **289 แถว** |
| หน้า PDF ที่ลงทะเบียนอ้างอิง | 40 หน้า |

**ยังไม่ระบุวันแข่งขันจริง**, บางประเภทไม่ระบุเวลา/สนาม, เลขคู่หรือรายการซ้ำในต้นฉบับ ให้ตรวจมติคณะกรรมการก่อนประกาศต่อครูและผู้ปกครอง

## เว็บไซต์

- `index.html`: ค้นหาตามโรงเรียน ชนิดกีฬา ชื่อคู่ รุ่นอายุ และกรีฑาพร้อมลู่
- คงป้าย **ต้นแบบ / ไม่ใช่ประกาศทางการ / ข้อมูลร่าง** บนทุกหน้า
- เว็บอ่านข้อมูลจาก `data/draft-schedule.json`; ไม่เปิดให้ผู้ชมทั่วไปแก้โปรแกรม
- หากเปิดใช้งาน GitHub Pages แล้ว หน้าเว็บจะอยู่ที่: https://infobwd.github.io/nongkum-sports-hub/ (ต้องตรวจสถานะเผยแพร่จริงก่อนส่งให้ผู้ปกครอง)
- เมื่อเลือกโรงเรียน จะเห็นคู่ที่โรงเรียนนั้นแข่งและลู่ที่ระบุชื่อโรงเรียนโดยตรง; การแข่งขันก่อนเรียนที่ลงในชื่อ **ศูนย์** ไม่ถูกจับคู่เป็นโรงเรียนโดยอัตโนมัติ

## UX-P2.1 — หน้าเว็บมือถือสำหรับผู้ปกครองและครู

ปรับหน้าสูจิบัตรให้ค้นหาเร็วขึ้นโดยคงข้อมูลร่างจาก PDF เดิม:

- ย่อส่วนหัวและคำเตือน โดยแสดงตัวเลือกโรงเรียนก่อนรายละเอียดอื่น
- กรองตามช่วงชั้น (ก่อนเรียน/ปฐมวัย, ประถม, มัธยม), โรงเรียน และกีฬา
- กรีฑาแสดงเฉพาะลู่ของโรงเรียนที่เลือกก่อน; `ดูทุกลู่` เพื่อเปิดข้อมูลครบ
- จัดกลุ่มผลลัพธ์ตามกีฬา และเปิดแสดงเพิ่มครั้งละ 12 รายการ
- ยุบสถานะวัน/เวลา/สนามรอยืนยันให้กระชับ พร้อมแยกข้อมูลที่ปรากฏใน PDF
- ย่อข้อมูลสำหรับผู้จัดให้เป็นลิงก์ไปคู่มือ P2 และ QA
- ทั้งหมดยัง **ข้อมูลร่าง / ยังไม่ใช่กำหนดการแข่งขันทางการ**

ตรวจสอบข้อจำกัดและ checklist มือถือใน [UX-P2.1 Mobile QA](docs/UX_P2_1_MOBILE_QA.md)

ทดสอบการกรองและการแสดงข้อมูลในชุด 236 รายการ:

```bash
node scripts/ux/test-mobile-ui.mjs
```

## UX-P2.2 — หน้าเว็บกระชับและข้อมูลคู่แข่งขันที่เปิดดูเพิ่มได้

- ย่อส่วนหัวและพื้นที่ค้นหา เหลือขั้นตอนหลัก **เลือกโรงเรียน → เลือกกีฬา**
- ตัวเลือกกีฬาบอกจำนวนรายการที่ตรงกับโรงเรียน/ตัวกรอง และแตะเพื่อดูเฉพาะกีฬานั้นทันที
- ย้ายตัวกรองช่วงชั้นและคำค้นไปไว้ที่ **ตัวกรองเพิ่มเติม** ซึ่งขยายเองเมื่อเปิดลิงก์ที่มีช่วงชั้น
- ย่อการ์ดคู่แข่งขัน โดยคงหน้า PDF รอบแข่งขัน เลขคู่และประเด็น QA ไว้หลัง **รายละเอียด · ข้อมูลร่าง**
- กรีฑายังคงเปิดดูทุกลู่ได้ จัดกลุ่มผลตามกีฬาและแสดงเพิ่มครั้งละ 12 รายการ
- เพิ่ม CSS safe-area สำหรับ iPhone และคงคำเตือนว่าข้อมูล **ยังไม่ผ่านการรับรอง**
- ดู [เกณฑ์ตรวจรับ UX-P2.2](docs/UX_P2_2_MOBILE_QA.md) — การทดสอบอัตโนมัติไม่ทดแทนการตรวจหน้าจอ iPhone/Android จริง

```bash
node scripts/ux/test-mobile-ui.mjs
```

## P2 — ฐานข้อมูลกรรมการ Google Sheets

- สร้าง native Google Sheets (6 แท็บ): ตั้งค่า, โรงเรียน, รายการ, คู่แข่งขัน, กรีฑา, ประกาศ; **ย้ายมาอยู่ใน Shared Drive โฟลเดอร์ปี 2569 เดียวกับ Google Docs สูจิบัตรแล้ว**

- ตรึงหัวตาราง, ตัวกรอง, dropdown สถานะ, ป้องกันรหัสต้นฉบับและคอลัมน์ผู้รับรอง, สูตรสถานะ
