# UX-R4 — รีเฟรช แชร์คู่/ผล และใบบันทึกผลการแข่งขัน A4

สถานะ: พัฒนาโค้ดในสาขา R4 / ผลการแข่งขันเผยแพร่จริงยังเป็น **0** รายการ

## 1. วิเคราะห์ UX จากภาพ iPhone (4 พฤศจิกายน 2569)

- เมนู **โปรแกรมการแข่งขัน / ผลการแข่งขัน** แยกชัดเจน อ่านง่ายบนมือถือ
- เลือกโรงเรียนเดียวกันข้ามหน้าได้แล้ว แต่ยังไม่เห็นว่าเปิดข้อมูลเมื่อใด
- หน้าผลไม่มีคะแนนจริง: empty state แสดงถูกต้อง ไม่ควรใส่ผลตัวอย่างในเว็บ
- มีการ์ดรายการจำนวนมาก: การแชร์ลิงก์รวมทำให้ผู้รับต้องเลือกโรงเรียนและค้นหาคู่ใหม่
- กรรมการควรมีใบบันทึกผลต้นทางที่ชัดเจน ก่อนเจ้าหน้าที่นำเข้าผล Google Sheets

## 2. รีเฟรชข้อมูลบน GitHub Pages

- เพิ่มปุ่ม `↻ รีเฟรช` ใน **ทั้งสองหน้า**
- ใช้ `fetch(...?refresh=timestamp,{cache:"no-store"})` อ่าน JSON **ฉบับที่เผยแพร่บน GitHub Pages** และคงตัวกรองที่เลือก
- หน้า **ผลการแข่งขัน** รีเฟรชอัตโนมัติทุก 5 นาที **เฉพาะเมื่อหน้านั้นยังเปิดแสดงอยู่**
- แสดงเวลาที่ **ตรวจไฟล์ล่าสุด** แยกจากเวลา `published_at` ของข้อมูลผลรับรอง; ไม่เขียนว่าเป็นเวลาอัปเดตจาก Google Sheets
- กรณีเครือข่ายผิดพลาด ยังคงข้อมูลล่าสุดที่โหลดไว้ และแสดงข้อความแจ้ง
- **ไม่ใช่ real-time sync:** Google Sheets ยังต้องผ่านผู้รับรอง ส่งออก JSON ตรวจไฟล์ และเผยแพร่ขึ้น GitHub Pages ก่อน จึงจะเห็นผลใหม่

## 3. แชร์ลิงก์เฉพาะคู่และผล

- โปรแกรม: ปุ่ม `แชร์คู่แข่งขัน` ส่งลิงก์ `index.html?fixture=<fixture_id>`
- ผล: ปุ่ม `แชร์ผลการแข่งขัน` ส่งลิงก์ `results.html?result=<result_id>`
- รับลิงก์แล้วให้ระบบกรองไปยังชนิดกีฬา/รายการนั้นโดยตรง ไม่ยึดโรงเรียนที่เคยเก็บไว้ในเครื่องผู้รับ และแสดงเฉพาะรายการที่มีอยู่
- แชร์ด้วย `navigator.share` เมื่ออุปกรณ์รองรับ มิฉะนั้นใช้ Clipboard API
- ชื่อ/วันที่ PDF และสถานะร่างบนการ์ดโปรแกรมยังปรากฏ ไม่สร้างคำว่า “ผลรับรอง” บนคู่ที่ยังร่าง
- **ไม่มีปุ่มแชร์ผลจริง** จนกว่า `data/public-results.json` จะมีผล `approved`

## 4. ใบบันทึกผลการแข่งขัน A4

ไฟล์ [`forms/score-sheet.html`](../forms/score-sheet.html) เป็นแบบฟอร์ม HTML พิมพ์ A4 แนวตั้ง สามารถใช้บนมือถือ/คอมพิวเตอร์แล้วกดพิมพ์หรือบันทึก PDF ได้

**องค์ประกอบที่ล็อกไว้ทุกชนิดกีฬา**

- หัวเรื่อง **มิตรภาพเกม 2569**
- รหัส `fixture_id` / `event_id`, ชนิดกีฬา, รุ่น, รอบ/คู่, วัน, เวลา, สถานที่/หมายเลขสนามย่อย, PDF ต้นฉบับ
- ชื่อสองโรงเรียนหรือข้อมูลกรีฑาตามลู่
- พื้นที่บันทึกผลที่แปรตามกีฬา; ช่องหมายเหตุกรณีเสมอ/ประท้วง/แก้ไข
- ลงชื่อ **ผู้บันทึกผล / กรรมการผู้ตรวจ / ผู้รับรองผล** และตัวเลือกสถานะ
- ไม่จำเป็นต้องเก็บชื่อเด็ก เลขประจำตัวเด็ก หรือเบอร์โทรผู้ปกครองในชุดนี้

**รูปแบบตามชนิดกีฬา**

| ประเภท | รูปแบบพิมพ์ |
|---|---|
| ฟุตบอล/ฟุตซอล/ยิงจุดโทษ | คะแนนทีม A/B ในแต่ละช่วงและคะแนนรวม |
| เปตอง | คะแนนเกม/แมตช์ (ไม่บังคับจำนวนเซ็ต หากมีหลายเกมให้กรรมการพิจารณาใช้ตารางเซ็ตตามกติกา) |
| วอลเลย์บอล/เซปักตะกร้อ/เทเบิลเทนนิส | คะแนนเกม/เซ็ต A/B และจำนวนเกม/เซ็ตที่ชนะ; ไม่สมมติว่าต้องเล่นครบ 5 เซ็ต |
| ชักเย่อ | ผลชนะ–แพ้และช่องบันทึกผลแต่ละยก |
| กรีฑา | ตารางลู่/อันดับ/โรงเรียน/สถิติ/หน่วย/หมายเหตุ (เติมโรงเรียนจาก PDF เมื่อเปิดจากลิงก์รายการ) |

**ขั้นตอน**

1. เปิดรายการจากหน้าโปรแกรม → `รายละเอียด` → `พิมพ์ใบบันทึกผล A4` เพื่อเติมข้อมูลเบื้องต้นตามสูจิบัตร
2. ตรวจวัน เวลา สนาม และชื่อทีมให้ถูกต้องก่อนเริ่มแข่ง เพราะบางรายการใน PDF ยังเป็นร่าง
3. กรรมการบันทึกผลจริงและลงนามในกระดาษ
4. เจ้าหน้าที่นำผลที่ตรวจรับแล้วเข้า Google Sheets `07_ผลประเภททีมคู่` หรือ `08_ผลกรีฑา`
5. ผู้รับรองดำเนินการใน Apps Script จึงส่งออก approved-only snapshot แบบส่วนตัวก่อนเผยแพร่

**ข้อจำกัด:** ช่องที่กรอกในหน้าใบบันทึกผลเป็นข้อมูลในหน้าเบราว์เซอร์ชั่วคราว **ไม่มีปุ่มบันทึก ส่ง API หรือเขียนเข้า Sheets** ควรพิมพ์หรือบันทึก PDF ก่อนออกจากหน้า
