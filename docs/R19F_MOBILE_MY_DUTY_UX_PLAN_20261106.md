# R19-F/UX — ปรับหน้าที่กรรมการของฉันสำหรับมือถือ

วันที่ 6 พฤศจิกายน 2569 | ต่อยอด R19-F Phase A/B หลัง PR #59 merged

## เป้าหมาย
- ค้นชื่อได้เร็วขึ้นโดยวางส่วนค้นหาก่อนข้อความอธิบายยาว
- แสดงหน้าที่ในร่างแบบสั้นและอ่านง่าย; วันปฏิบัติหน้าที่ต้องระบุว่ารอผู้จัดยืนยัน
- แยกวันแข่งขันระดับชนิดกีฬาออกจากวันปฏิบัติหน้าที่ของครูอย่างชัดเจน
- ยุบรายละเอียดวันแข่งขันและเลขอ้างอิง PDF ไว้ในส่วนกดขยาย แต่ข้อมูลทุกบรรทัดยังอยู่ครบ
- ใช้ภาษาไทยทั่วไป ลดข้อความเตือนซ้ำ; คงป้ายสถานะร่างที่เห็นชัด

## ขอบเขต
แก้เฉพาะ committee.html, css/committee.css, js/committee.js และชุดทดสอบกรรมการตามจำเป็น; ไม่แก้ program, fixture JSON, results, standings, Google Sheets, Apps Script, ระบบตรวจรายชื่อ committee-review.html หรือกติกาอนุมัติ.

## ข้อห้าม
ไม่อนุมานวันหรือเวลาเข้าเวรจากวันแข่ง; ไม่รวมคนชื่อซ้ำข้ามโรงเรียน; ไม่เปลี่ยนแหล่งข้อมูลหรือสถานะร่าง; ไม่ลดจำนวนหน้าที่ที่ค้นพบ; ไม่แตะการแก้ฟุตบอลหญิง 18 พ.ย. ของ R20-B.

## ตรวจรับ
1. เลือกโรงเรียน/ค้นชื่อ/ชื่อซ้ำ/หลายหน้าที่และสลับโรงเรียนได้เหมือนเดิม
2. การ์ดสรุปแสดงบทบาทกับสถานะรอรับรองก่อน; วันแข่งขันอยู่ใน details กดขยายได้
3. ไม่สื่อว่าวันแข่งคือวันทำงาน; รายการที่ยืนยัน/ร่าง/ไม่ทราบยังแยกครบ
4. iPhone Safari และ LINE WebView ต้องตรวจจริงก่อนปิด QA
5. CI และ regression ผ่านก่อน merge; การ merge ไม่ใช่หลักฐานตรวจรับมือถือจริง
