# R11C V4.2-N2 — คืนรูปแบบย่อหน้า «มีหน้าที่» และตรวจสระ/วรรณยุกต์ในประกาศ

วันที่: 7 พฤศจิกายน 2569 | สถานะ: IMPLEMENTATION PLAN (REVIEW ONLY) | ฐาน: `main` หลัง PR #97
สืบเนื่องจากผู้จัดทักว่า งานแก้พยัญชนะ–สระ–วรรณยุกต์ และเนื้อหา «มีหน้าที่» ที่เคยทำไว้ยังไม่ครบในเล่ม V42-N1

## หลักฐานที่ตรวจจริง

- รุ่น V42-N1 อยู่ใน Drive เป็น PDF review 126 หน้า A4: หน้า 8 เป็นหน้าเปิดแบบ V4.1 หน้า 9–19 เป็นถอดประกาศ V3 หน้า 6–16 และหน้า 20 เป็นต้นไปเป็นตารางตรวจกรรมการ; ยังไม่ใช่ประกาศที่ลงนาม
- ต้นฉบับ V3 ใส่ «มีหน้าที่ ...» **ต่อจากรายชื่อคณะกรรมการแต่ละฝ่ายในประกาศเดียวกัน**; source model V42-A ตรวจได้ 341 บรรทัด / 20 หมวด / 231 member / **20 duty starts**. มี **14 บรรทัดต่อเนื่อง** ที่ PDF ต้นฉบับตัดบรรทัดระหว่างข้อความหน้าที่ (ตรวจตาม predicate source)
- PDF ล่าสุดเรนเดอร์ «มีหน้าที่» บรรทัดแรกเป็นแถบสีฟ้า ส่วนเนื้อหาต่อบรรทัดแสดงเป็นย่อหน้าปกติแยก ทำให้เนื้อหาที่ควรต่อเนื่องดูเหมือนคนละส่วน และ `ต้นฉบับ V3 · หน้า ...` + `341 บรรทัด` ปรากฏในหน้างานเอกสารทางการ
- ฟอนต์ส่วนประกาศ PDF **ฝัง Sarabun Regular/Bold จริง** (ตรวจ text span เป็น `FormalThai`/ `FormalThai-Bold`; `formal_font` รายงาน `Sarabun (Google Fonts, OFL)`). ต้องรักษา full Regular/Bold และการปรับสระอำให้คัดลอกได้ โดย **ห้ามใช้การเลื่อนวรรณยุกต์ด้วย CSS หรือการตกแต่งย้าย glyph**
- เกณฑ์ QA ปัจจุบันตรวจ `a`/semicolon แทรกและ 341 บรรทัด แต่ **ไม่ได้ตรวจว่า duty line + continuation รวมเป็นย่อหน้าเดียว**. ต้องเพิ่ม regression

## ขอบเขตแก้ V42-N2

1. **คืนข้อความหน้าที่แบบประกาศ:** ใน `v42_official.py` รวบข้อความขึ้นต้น `มีหน้าที่` กับบรรทัดต่อเนื่องเป็น **ย่อหน้าเดียว** โดยคง `data-source-line` ครบและเรียงเดิม อ้างอิง source-page/line; สำหรับข้อความที่เป็นชื่อหัวข้อใหม่ เช่น `ฝ่ายเชิญเหรียญ/ถ้วยรางวัล` ต้องปิดย่อหน้าก่อน ไม่ดูดเข้าเป็นเนื้อหาหน้าที่
2. เปลี่ยนสไตล์ `v42-duty-line` แถบสีข้อมูลเป็น **ย่อหน้าทางการตามลำดับคณะกรรมการ**: ไม่มีกรอบ/พื้นสี; เน้นเพียงคำว่า «มีหน้าที่» และเว้นย่อหน้าให้อ่านต่อเนื่อง. บรรทัดต่อใช้ inline spans ไม่มีแถบแยก
3. ไม่แสดงป้ายตัวเลขหน้าต้นฉบับหรือคำอธิบาย QA เชิงเทคนิคบนหน้าประกาศสำหรับผู้จัด; ยังต้องมี audit/source link ใน HTML/QA JSON ภายในและยังระบุ **ร่าง/รอตรวจ** บนหน้า PDF เพื่อไม่แสร้งเป็นคำสั่งทางการ
4. คงฟอนต์ Sarabun Regular/Bold ครบ (Google Fonts OFL) และวิธีรักษาสระอำที่ตรวจผ่าน; เพิ่ม QA สำหรับ font spans/Thai PDF text layer และ visual page diff. **ไม่เปลี่ยนข้อความ V3 เพื่อแก้สะกดโดยคาดเดา**
5. คงหน้าเปิดประกาศ N1 ใน PDF **หน้า 8** แบบที่ผู้จัดเคยชอบ, และถัดไปให้เนื้อหา full-source อ่านเหมือนประกาศต่อเนื่อง (ต้องตรวจจำนวนหน้าใหม่, ห้าม fix 126)
6. **แยกชัด:** «มีหน้าที่» เป็นเนื้อหาในประกาศแต่งตั้งคณะกรรมการ (ร่าง) ไม่ใช่คอลัมน์ `หน้าที่` ในตารางตรวจชื่อ ซึ่งจริง ๆ ใช้แสดง **ตำแหน่งในคณะกรรมการ** (ประธาน/กรรมการ/เลขานุการ) ให้แก้หัวตารางชื่อว่า `ตำแหน่ง/บทบาท` ไม่ใช้คำว่า `หน้าที่` ทำให้ผู้อ่านสับสน
7. ห้ามเปลี่ยน data source, การแข่งขัน 236 รายการ, รายการกรรมการ 250, 486 anchors, ข้อสังเกตผังสาย 6 กลุ่ม, 17 หน้า V3 appendix, rights-gated Full Photo cover, หรือ GitHub Pages/public PDF
