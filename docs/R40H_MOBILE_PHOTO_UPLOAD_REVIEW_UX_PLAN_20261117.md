## ขอบเขตดำเนินการ
1. ส่งภาพสำเร็จ: แผงยืนยันความสำเร็จชัดเจน (ชื่อการแข่งขัน/สถานะ “ส่งแล้ว รอผู้ตรวจ”/รหัสอ้างอิง), ปุ่ม “ส่งภาพเพิ่มในรายการนี้” และ “ดูสถานะภาพที่ส่ง” ไม่ลบฟอร์มโดยไม่แจ้ง, ไม่เปลี่ยนการรับภาพ private ก่อนตรวจ
2. ส่งภาพอยู่ระหว่างประมวลผล: แจ้ง กำลังย่อ/กำลังส่ง พร้อมล็อกปุ่มป้องกันแตะซ้ำ; กรณีเครือข่ายไม่ทราบผล ต้องสื่อสารว่า “ยังยืนยันไม่ได้” ไม่สั่งอัปโหลดซ้ำอัตโนมัติ
3. ค้นหารายการ iPhone/LINE: Select2 ใช้ช่องแสดงข้อความสั้นตัดด้วย ellipsis ภายใน viewport และแสดงรายละเอียดการเลือกแบบแบ่งบรรทัดด้านล่าง; fallback native select ยังใช้งานได้เมื่อ CDN ไม่พร้อม
4. ภาพที่ส่ง: เพิ่ม endpoint แบบอ่านอย่างเดียว `mine` รับเฉพาะ editor session token ตรวจ hash และ expiry ฝั่ง SQL, กรองเฉพาะ session นั้น ไม่เปิดการอ่าน private ภาพหรือข้อมูลทุกโรงเรียน; ซ่อนข้อมูลเมื่อสิทธิ์หมดอายุและไม่เก็บข้อมูลภาพส่วนตัวบนเครื่อง; ระบุว่า “รายการที่ส่งในช่วงสิทธิ์นี้”
5. ตรวจภาพ: แท็บ “รอตรวจ / เผยแพร่แล้ว / เก็บไว้ภายใน / ถอนภาพแล้ว”, แสดงจำนวนตามสถานะและการ์ดไม่ปะปน; วางคำอธิบายใต้หัวเรื่องให้อ่านสั้น; ปุ่มหลัก “อนุมัติเผยแพร่” รองลงมา “ส่งกลับแก้ไข”, การเก็บภายในย้ายไปเมนูเพิ่มเติม; ช่องหลักฐานตรวจสิทธิ์ยังจำเป็นและต้องเป็นรายภาพ
6. ปรับ validation ให้แสดงใกล้ช่องข้อมูล, ล้าง error ที่ล้าสมัยหลังแก้ไข, ไม่ล้าง checkbox หลักฐานเอง, ไม่ข้ามการยืนยันสิทธิ์เผยแพร่ภาพบุคคล/นักเรียน
7. รักษา R32/R33/R39/R40/R40-G/R41, รูป WebP/JPEG, offline fallback, อัปโหลดภาพเก็บใน private โดยไม่แก้ผลการแข่งขัน
