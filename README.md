# กีฬากลุ่มหนองกุ่ม — Nongkum Sports Hub 2569

พื้นที่ส่วนกลางสำหรับข้อมูลการจัดการแข่งขันกีฬา การประชุม คำสั่งคณะกรรมการ และสูจิบัตรออนไลน์บนมือถือ

## สถานะปัจจุบัน: P1 — นำเข้าจาก PDF ครบ แต่ยังไม่อนุมัติ

**ข้อมูลจาก PDF ทั้ง 40 หน้าได้รับการจัดหมวดและถอดโปรแกรมการแข่งขันแล้ว — ทุกแถวเป็น DRAFT ไม่ใช่ประกาศการแข่งขันทางการ**

| สิ่งที่นำเข้า | จำนวน |
|---|---:|
| โรงเรียน | 8 |
| หมวดกีฬา/กิจกรรมสำหรับค้นหา | 9 |
| รุ่น/ประเภทที่มีเลขกำกับในผัง | 33 |
| ตำแหน่งรายชื่อทีมตามผัง | 177 |
| คู่แข่งขันในโปรแกรม | **186 คู่** |
| รายการกรีฑา | **50 รายการ** |
| แถวลู่กรีฑา | **289 แถว** |
| หน้า PDF ที่ลงทะเบียนอ้างอิง | 40 หน้า |

**ยังไม่ระบุวันแข่งขันจริง**, บางประเภทไม่ระบุเวลา/สนาม, เลขคู่หรือรายการซ้ำในต้นฉบับ ให้ตรวจมติคณะกรรมการก่อนประกาศต่อครูและผู้ปกครอง

## เว็บไซต์

- `index.html`: ค้นหาตามโรงเรียน ชนิดกีฬา ชื่อคู่ รุ่นอายุ และกรีฑาพร้อมลู่
- คงป้าย **ต้นแบบ / ไม่ใช่ประกาศทางการ / ข้อมูลร่าง** บนทุกหน้า
- เว็บอ่านข้อมูลจาก `data/draft-schedule.json`; ไม่เปิดให้ผู้ชมทั่วไปแก้โปรแกรม
- หากเปิดใช้งาน GitHub Pages แล้ว หน้าเว็บจะอยู่ที่: https://infobwd.github.io/nongkum-sports-hub/ (ต้องตรวจสถานะเผยแพร่จริงก่อนส่งให้ผู้ปกครอง)
- เมื่อเลือกโรงเรียน จะเห็นคู่ที่โรงเรียนนั้นแข่งและลู่ที่ระบุชื่อโรงเรียนโดยตรง; การแข่งขันก่อนเรียนที่ลงในชื่อ **ศูนย์** ไม่ถูกจับคู่เป็นโรงเรียนโดยอัตโนมัติ

## ทดสอบ

```bash
node scripts/validate-data.mjs
```

ทดสอบ integrity: จำนวนคู่/รายการ/ลู่ตาม PDF, หมายเลขซ้ำที่ต้องคงไว้, การเชื่อมโรงเรียนและรายการ, `source_page`, ไม่มีวันแข่งขันที่สมมติขึ้นมา, ทุกแถวเป็น draft, JavaScript syntax และป้ายเตือนบนเว็บ

เปิดหน้าเว็บในเครื่องผ่านเว็บเซิร์ฟเวอร์ เช่น

```bash
python -m http.server 8000
# เปิด http://localhost:8000
```
