P2 **ยังไม่มีระบบเผยแพร่ข้อมูลอัตโนมัติไป GitHub Pages** และไม่ได้เปลี่ยนข้อมูล `data/draft-schedule.json` ในเว็บให้เป็น `approved`; การส่งไปเว็บสาธารณะเป็น P3

- ห้ามกรอกวัน/เวลาที่เอกสารไม่ได้ระบุด้วยการคาดเดา

- กลุ่ม `ก่อนเรียน (ศูนย์ฯ)` ไม่แปลงเป็นโรงเรียนรายแห่งโดยเดา; ลู่ต้นฉบับเครื่องหมาย `-` ไม่ถูกนับเป็นผู้เข้าแข่ง
- ชื่อเด็ก เบอร์โทร และภาพเด็กไม่อยู่ใน Google Sheet ชุดนี้

## สิทธิ์/การป้องกัน

- Drive file อยู่สถานะ **private / ไม่แชร์สาธารณะ** ณ วันที่สร้าง
- คอลัมน์รหัส, ชื่อทีมตาม PDF, เลขที่/หน้า PDF, ลู่และข้อมูลโรงเรียนที่อ้างอิงต้นฉบับถูกป้องกันแก้ไขโดยเจ้าของบัญชี `info@bwd.ac.th`
- คอลัมน์ผู้รับรอง / รับรองเมื่อ / `approval_digest` ถูกป้องกันแก้ไขเช่นกัน
- กรรมการที่ได้รับสิทธิ์ Editor จะแก้วัน–เวลา–สนาม–หมายเหตุและเปลี่ยนสถานะเป็น `review` ได้ แต่การ `approved` ที่มีผลสำหรับตัวส่งออกต้องผ่านผู้รับรองที่ได้รับสิทธิ์
- ผู้จัดต้องระมัดระวังการให้สิทธิ์แก้ไข Google Sheet เพราะ **การป้องกันคอลัมน์ไม่ใช่ระบบรักษาความปลอดภัยแทนการจำกัดการเข้าถึงบัญชี**

## กติกาอนุมัติและป้องกันแก้หลังอนุมัติ

มีตัวอย่าง Apps Script ใน `apps-script/Code.gs` แต่ **ยังไม่ได้ติดตั้งในชีทโดยอัตโนมัติ** (เครื่องมือเชื่อมต่อที่ใช้แก้ชีทไม่ได้ติดตั้งโครงการ Apps Script ให้)

ผู้มีสิทธิ์ควรรับรองผ่านเมนู `กีฬาหนองกุ่ม P2 → รับรองแถวที่เลือก` หลังติดตั้ง ไม่ใช่พิมพ์ `approved` อย่างเดียว เพราะเมนูจะ:

1. ตรวจช่องบังคับ (วัน `YYYY-MM-DD`, เวลา `HH:mm`, สนาม, ชื่อรายการ/ทีม)
2. ถ้ามี QA flag ต้องมีบันทึกมติในหมายเหตุ
3. เขียนสถานะ `approved`, อีเมลผู้รับรอง, เวลา และ **SHA-256 approval_digest** ของข้อมูลต้นทาง/ข้อมูลธุรกิจ
4. การแก้แถวที่ได้รับอนุมัติแล้วจะทำให้ digest ไม่ตรง และตัวส่งออกปฏิเสธแถวนั้นจนรับรองใหม่

### ขั้นตอนติดตั้ง Apps Script (ผู้ดูแลบัญชีโรงเรียนทำเพียงครั้งเดียว)

1. เปิด Google Sheet ที่สร้างใน P2 → **Extensions → Apps Script**
2. คัดลอกโค้ดจาก [`apps-script/Code.gs`](../apps-script/Code.gs) ไปแทนเนื้อหา `Code.gs`; บันทึก
3. ไป **Project Settings → Script properties** เพิ่ม:
   `NONGKUM_APPROVER_EMAILS` = อีเมลผู้มีสิทธิ์อนุมัติ คั่นด้วย comma (เริ่มจากบัญชีเจ้าของชีท)
4. ทดสอบฟังก์ชัน `nkShowReadiness` และอนุญาตสิทธิ์เฉพาะที่ Google แจ้งสำหรับ Apps Script ที่ตรวจสอบโค้ดแล้ว
5. โหลด Sheet ใหม่ จะเห็นเมนู `กีฬาหนองกุ่ม P2`; ทดลอง 1 รายการที่วัน/เวลา/สนามได้รับมติจริงเท่านั้น
6. ถ้าเพิ่มผู้รับรองหลายคน ต้องเพิ่มอีเมลนั้นในการป้องกันคอลัมน์ผู้รับรอง/เวลารับรอง/`approval_digest` ด้วย และทบทวนสิทธิ์การแก้ไข Script

**ข้อจำกัดจริง:** การแก้ไข Apps Script โดยผู้มีสิทธิ์ Editor และการกรอกสถานะ `approved` ด้วยมือยังต้องใช้การควบคุมสิทธิ์และการตรวจสอบ version history; SHA-256 เป็นเครื่องมือตรวจการเปลี่ยนแปลง **ไม่ใช่ลายเซ็นดิจิทัลหรือหลักฐานพิสูจน์ตัวบุคคล** ในทางกฎหมาย

## ตัวส่งออก approved-only (P2 staging)

เมื่ออนุมัติอย่างน้อยหนึ่งรายการ เจ้าของบัญชีใช้เมนู
`สร้าง JSON เฉพาะ Approved ใน Drive ส่วนตัว`

ระบบจะ:
- ตรวจผู้ส่งออกกับ allowlist `NONGKUM_APPROVER_EMAILS` และปฏิเสธกรณีอีเมลไม่ชัดเจน
- ตรวจ `approved` + ผู้รับรอง/เวลา + digest ที่ตรง + QA notes
- คู่แข่งขันต้องมีประเภทแม่และโรงเรียนที่เกี่ยวข้องได้รับอนุมัติ, วัน เวลา สนามครบ
- กรีฑาต้องรับรองครบ **ทุกลู่ที่มีทีม** ในรายการเดียวกัน จึงจะส่งออกรายการนั้น
- ปฏิเสธหากมีข้อมูล Approved ที่มีปัญหา; ถ้ายังไม่มี Approved เลยก็ไม่ส่งออก
- ตัด metadata ผู้รับรองและ `approval_digest` ออกจาก JSON สำหรับเผยแพร่
- สร้างไฟล์ `nongkum-approved-snapshot-YYYYMMDD-HHmmss.json` ใน **Drive ส่วนตัวของผู้เรียก**
- **ไม่ส่งข้อมูลขึ้น GitHub และไม่แตะระบบเว็บสาธารณะ** จนกว่า P3 ผ่านขั้นตรวจซ้ำ
