## ผลตรวจทางเทคนิค

- PDF **6 หน้า** ทุกหน้า A4 595.28 × 841.89 pt
- ฟอนต์ไทยฝังใน PDF (Noto Sans Thai subset) และสามารถอ่านข้อความ/ค้นหาได้
- ไม่มี text-span หลุดขอบหน้ากระดาษที่ตรวจด้วย PyMuPDF
- Render ทุกหน้าเป็น PNG และตรวจ contact sheet แล้ว; ยังต้องตรวจบน iPhone, LINE WebView และพิมพ์ 100% บน A4 จริง
- เฉพาะต้นแบบนี้ใช้แม่แบบสีกรมท่า–เหลือง; ในเล่มจริงควรทดสอบการพิมพ์ขาวดำและความเข้มหมึกด้วย
- **ตัวอย่าง 6 หน้าเป็นตัวแทนรูปแบบ ไม่ใช่เอกสาร 64 หน้าแบบเดียวกับ V3 และไม่ใช่ PDF V4 เต็มเล่ม**

## การตัดสินใจสำหรับงานขั้นถัดไป

1. ตรวจรับงานออกแบบ 6 หน้าก่อน โดยเฉพาะการจัดคอลัมน์รายชื่อ, กรีฑา และพื้นที่เขียนใบบันทึกผล
2. รอผล PR #73 ในการเลือกชื่อกรรมการฉบับล่าสุดและตรวจการสะกด; ไม่แก้ทับ working copy ใน Docs โดยไม่ตรวจ revision
3. หากยืนยันแล้ว ให้แปลงแม่แบบเป็น generator ที่อ่าน data model แบบ deterministic ครบทุกชนิดกีฬา; เก็บสคริปต์ layout และทดสอบ output hash
4. เมื่อสร้าง PDF V4 เต็มเล่ม ต้องคำนวณตำแหน่งรายการแข่ง 236 IDs และกรรมการ 250 IDs จาก PDF **ใหม่จริง** ไม่ reuse หน้า/pixel เดิม
5. ส่งผลให้ R11E ตรวจรับก่อนเปลี่ยน PDF บนเว็บไซต์; V2/V3 และวิธีเปิดเดิมคงอยู่ตลอดช่วงทดลอง

## Scope / Non-goals

ไม่ได้แก้แหล่งข้อมูลการแข่งขัน, PDF V3/V2, รายชื่อกรรมการ PR #73, ผลการแข่งขัน, Google Sheets, หรือเว็บไซต์. งานนี้คือ **design preview and visual QA**, ไม่ใช่ release.
