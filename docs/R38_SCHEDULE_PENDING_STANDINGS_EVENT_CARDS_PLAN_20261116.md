## เป้าหมาย
1. หน้าตารางเริ่มที่ “ยังไม่มีผลรับรอง” โดย join fixture/event ID กับ R32 approved-only; คงทางเลือก “ทั้งหมด” และแยกสถานะรอตรวจจากสถานะรับรอง; หากอ่านผลสดไม่สำเร็จให้แจ้งและอย่าซ่อนรายการด้วยข้อมูลเก่าอย่างไม่แจ้ง
2. ผู้ตรวจ R37 ที่ล็อกอินแล้วกดการ์ดเพื่อไปบันทึกได้โดยไม่ต้องใส่รหัสสองครั้ง: ต้องมีการตรวจ session ผ่าน backend ไม่ให้ฝั่ง browser แอบอ้างสิทธิ์; ไม่เปลี่ยนสิทธิ์เผยแพร่ของผู้บันทึก
3. ตารางคะแนนรายสายฟุตบอล/ชนิดกีฬาที่มีลีก: แสดงรายชื่อและศูนย์ก่อนมีผล, ไม่กำหนดอันดับจริง, แยกสายจาก fixture source ที่ตรวจได้เท่านั้น; กีฬาแพ้คัดออกแสดงผังแทนลีก; เกณฑ์ยังไม่รับรองต้องไม่ประกาศอันดับ
4. การ์ดผลแสดงชื่อรายการย่อย (เช่น วิ่ง 40 ม. หรือ วิ่งผลัด) จาก ID ที่ตรงกับแหล่งตาราง ไม่ใช้ regex เดาจากรหัส; แสดงภาพกีฬา WebP ขนาดเล็ก load lazy หรือ fallback ที่เหมาะสม, ไม่เก็บภาพหลักฐานหรือข้อมูลส่วนบุคคล
5. รักษาปุ่มแชร์ผล R36, รายการ/PDF, deep link, ปุ่มบันทึกผล และ cache PWA; ทดสอบมือถือ Safari/Chrome/LINE หลัง PR
