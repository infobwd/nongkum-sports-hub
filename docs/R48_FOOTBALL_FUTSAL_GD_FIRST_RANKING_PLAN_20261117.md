# R48 — ฟุตบอลและฟุตซอล: คะแนน → ผลต่างรวม → พบกันเอง (17 พฤศจิกายน 2569)

## ที่มาจากผู้จัด
- 17 พฤศจิกายน 2569: ยืนยันให้ใช้ **คะแนนสะสมมากก่อน** หากเท่ากันให้ดู **ผลต่างประตูได้–เสียรวมทุกคู่ที่รับรองแล้ว** ก่อนดูผลการพบกันเอง (Head-to-Head)
- คำสั่งต่อเนื่อง: **ฟุตซอลใช้แบบเดียวกับฟุตบอล**
- ไม่ใส่ "ประตูยิงได้มากกว่า" คั่นระหว่างผลต่างประตูรวมกับ Head-to-Head เพราะผู้จัดยืนยันให้ไปดู Head-to-Head โดยตรง
- ฟุตบอลคงเกณฑ์ใบแดงน้อยกว่า ต่อด้วยใบเหลืองน้อยกว่า *เฉพาะเมื่อครบผลลีกและบันทึกใบทุกคู่ครบ*; ฟุตซอลใช้เกณฑ์เดียวกันเมื่อมีข้อมูลใบครบทุกคู่ของสาย
- ข้อมูลยังไม่พอตัดสินให้แสดง **อันดับร่วมชั่วคราว** ห้ามเดาตำแหน่งเข้ารอบ

## ตรวจระบบเดิม
- main มี R46/PR #175 แล้ว: `js/standings-rosters-r38.js` เรียงผลพบกันเองก่อน ผลต่างรวมจึงไม่ถูกใช้
- `js/standings-engine.js` ใช้กติกาผลพบกันเองสำหรับฟุตบอลเมื่อได้รับอนุมัติทั้งหมด
- ฟุตซอล 10 ปีชายแบ่งสาย A 4 ทีม 6 นัด, สาย B 3 ทีม 3 นัด จากรอบแรก; รอบรอง/รอบชิงไม่ใช่กลุ่มสะสมคะแนน
- `data/standings-rules.json` ฟุตซอลยังรอเกณฑ์อื่น ๆ เช่นการเข้ารอบและกรณีคะแนนเท่ากันที่ไม่อาจตัดสินด้วยข้อมูลที่มี

## ขอบเขตแก้
1. อัปเดตกติกาใน JSON พร้อม provenance วันที่ 17 พ.ย. / version ใหม่ โดยคงสถานะที่ยังไม่รับรองด้านการเข้ารอบและเผยแพร่ standings snapshot
2. แสดงอันดับชั่วคราวฟุตบอลและฟุตซอลรายสายจาก **เฉพาะผลรับรอง**, 3/1/0; คะแนน > ผลต่างรวม > GD พบกันเองเมื่อผลที่จำเป็นครบ > ใบแดง/ใบเหลืองเมื่อผล+บันทึกครบตามเงื่อนไข
3. ผลต่างรวมเท่ากันและ Head-to-Head ยังไม่ครบ: อันดับร่วม; ผลต่างรวมต่างกันไม่ต้องรอผลพบกันเอง
4. ในกลุ่ม 3 ทีมขึ้นไปใช้ mini-table เฉพาะทีมที่เสมอทั้งคะแนนและผลต่างรวม; ป้องกันการใช้ H2H ข้ามกลุ่มผลต่าง
5. สถานะอันดับยังเป็น `provisional`, `position` อย่างเป็นทางการไม่เปลี่ยน; ไม่แตะข้อมูลผล R32, ตาราง/ผัง R33, สูจิบัตร และกีฬาอื่น
6. คง UI มือถือ/ตัวกรอง/รีเฟรช; อธิบายกติกาบนหน้าให้ครูเห็น
