# R15-B/C — ข้อกำหนดเพิ่มเติมฟุตบอลบัตรเหลือง–แดง และเปตองแพ้คัดออก (6 พฤศจิกายน 2569)

**บันทึกแผนก่อนปรับโค้ด** — ได้รับคำยืนยันจากผู้จัดการแข่งขันในบทสนทนา

## ฟุตบอล 12 ปีชาย
- คงเกณฑ์หลัก: คะแนนชนะ 3 เสมอ 1 แพ้ 0; คะแนนเท่ากันดูผลต่างประตูจากการพบกันเอง (Head-to-Head GD) ตาม `R15BC_FOOTBALL_HEAD_TO_HEAD_GD_20261106.md`.
- ถ้าเกณฑ์ H2H ยังแยกไม่ได้ ให้ใช้ **ใบเหลืองและใบแดง** เป็นเกณฑ์ประกอบการตัดสินต่อไป. ผู้จัดยังไม่ได้กำหนด **น้ำหนักใบเหลือง/ใบแดง ลำดับการพิจารณา ใบแดงจาก 2 ใบเหลืองนับซ้ำหรือไม่ การนับเฉพาะเกมพบกันเองหรือทั้งลีก**; จึงเก็บการ์ดที่ตรวจรับไว้แยกประเภท แต่ **ห้าม auto-rank ด้วยสูตรที่เดาขึ้นเอง**.
- สัญญาผลฟุตบอลแบบ approved: `disciplinary_cards.team_a.yellow/red` และ `team_b.yellow/red` เป็นจำนวนเต็ม >=0 ที่เจ้าหน้าที่รับรองจากใบบันทึกแข่งขัน; **ศูนย์ต้องระบุ 0 จริง** ห้ามอนุมาน missing=0, เก็บยอดต่อโรงเรียน ไม่เก็บชื่อนักกีฬาในไฟล์สาธารณะ. แอปนำเข้าจากภาพและ Google Apps Script ต้อง map ข้อมูลนี้ก่อนเผยแพร่ผลฟุตบอลจริง
- ลีกแสดง `yellow_cards`, `red_cards` เฉพาะผลนัดลีกที่ approved และบัตรครบ; หากยังคำนวณอันดับไม่ได้ `position=null` และระบุ `card_tie_break_status=pending_count_method`.
- ผล 15 นัดลีกแยกจาก semifinal 17–18 และ final 19; ไม่มีผลจริงใน repo; `football_league.approval_status` ยัง pending.

## เปตอง
- **แพ้คัดออก (single-elimination)**: ชนะเข้ารอบถัดไป แพ้ตกรอบในสายของรุ่นนั้น; ไม่คิดคะแนนลีก/ตารางพบกันหมด; ห้ามจัดอันดับแพ้คัดออกโดยอัตโนมัติหากไม่มีหลักฐานรอบชิงที่ 3
- โปรแกรมที่ตรวจจาก `data/program-from-pdf-2569-20261104-draft.json` = **58 คู่**: 8 รุ่นมีรอบแรก 4 คู่ + รอบรอง 2 + รอบชิง 1 (รุ่นละ 7); มัธยมชาย/หญิงมีรอบชิงรุ่นละ 1 คู่. คู่รอบถัดไปบางรายการยังระบุ “ผู้ชนะคู่...” ไม่ใช่รายชื่อทีมจริง
- กติกาจำนวนเซ็ตในร่าง V2: ปฐมวัย 1 เซ็ตถึง 11 ทุกนัด, ประถมรอบแรก/รอง 1 เซ็ตถึง 11 และรอบชิงชนะ 2 ใน 3 เซ็ต เซ็ตละ 11, มัธยมชิงชนะ 2 ใน 3 เซ็ต. **ยังไม่ถือว่ารับรองจำนวนเซ็ตทุกกรณีจากคำสั่งแพ้คัดออกเท่านั้น**
- บันทึกสถานะ `elimination_status=approved`, `format=knockout`, `advancement=winner_only`. คง `sport_policies.petunque.status=pending_rule_approval` (ใช้ key จริง `petanque`) จน mapping ผู้ชนะ→คู่ถัดไปและจำนวนเซ็ตได้รับการตรวจรับ

## Acceptance / Release Gate
1. ฟุตบอลผล approved ที่ขาดช่องใบเหลือง/แดง → ไม่ผ่าน validation; ศูนย์ที่ระบุครบ → ผ่าน; ค่าเป็นลบ/ทศนิยม/สตริง → ไม่ผ่าน; เปลี่ยนยอดการ์ดต้องเพิ่ม revision และเหตุผลเช่นเดียวกับการแก้คะแนน
2. ตารางฟุตบอลรวมยอด yellow/red แบบแยกทีม โดยนับเฉพาะ fixture ใน league; ห้ามการ์ดจากรอบรองหรือรอบชิงเข้าลีก
3. เมื่อ H2H GD ยังเสมอ แม้ใบเหลือง–แดงต่างกัน **ห้ามเลือกอันดับเอง** จนอนุมัติวิธีคิด
4. เปตองผู้ชนะก้าวหน้า ผู้แพ้ตกรอบ **เฉพาะผล approved**; ทดสอบ invalid/duplicate/mismatched winners; ห้ามสร้างผลหรือ advancement ไปยัง placeholder โดยอัตโนมัติ
5. ใช้ CI R15-B/C, baseline UI/R15-A, R14, data validation; merge เฉพาะที่ตรวจผ่าน
