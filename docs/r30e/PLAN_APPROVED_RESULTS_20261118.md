## วิธีทำเพื่อรักษารูปหน้าและความถูกต้อง
1. สร้าง snapshot แบบอ่านอย่างเดียวของ view `nongkum_published_results` มี ID + result + revision + published_at; ไม่ใช้ข้อมูลที่เพียง `approved` ในช่องรับผลก่อนเผยแพร่.
2. เทียบรหัส fixture / event กับแถวใน PDF โดยตรวจชนิดกีฬา วัน รุ่น คู่แข่ง และเลขคู่ก่อนวางผล; หากขัดแย้งต้อง **ไม่ใส่ผลในแถวนั้น** และจัดในรายงานตรวจข้อขัดแย้ง.
3. กีฬาแบบ score แสดงคะแนนตามทีม A/B ตรงตัวเลขจริง; win_loss แสดง `ชนะ: โรงเรียน...` ไม่เดาคะแนน; sets แสดงผลนับเซตตามหลักฐาน; athletics ใส่อันดับตามรายการและโรงเรียนที่ตรงกับ source โดยไม่แต่งชื่อผู้แข่งขัน.
4. ห้ามปิดทับชื่อคู่แข่งขัน สนาม เวลา พื้นแถว วันที่เดิม หรือสะกดชื่อเปลี่ยน. ใช้พื้นที่เฉพาะคอลัมน์ผล/อันดับ/หมายเหตุ หรือเพิ่มแถบผลที่มีขอบเขตปลอดภัย; หากหน้าเดิมใส่ไม่ลงให้เพิ่มหน้า 'ผลรับรองรายคู่/กรีฑา' พร้อมลิงก์จากแถวเดิม.
5. เปลี่ยนสถานะร่างเฉพาะส่วนที่ได้รับรองผล; ไม่อ้างว่าตารางวันเวลา / ผังทั้งหมดถูกรับรองจากการมีผลแข่งขัน.
