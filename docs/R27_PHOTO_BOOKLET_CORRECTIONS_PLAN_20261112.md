## ข้อขัดแย้งที่ยังไม่แก้เดา

- ผังเปตอง 10 ปีชาย (เมื่อแก้ทีม 2 เป็นเสาหงส์) จะเรียง 1 หนองกระทุ่ม, 2 เสาหงส์, 3 รางขาม, 4 ทุ่งมะสังฯ แต่ **ตารางคู่ 2 ยังเป็น รางขาม – หนองกระทุ่ม**, ขัดกับผัง 3–4. ผู้จัดต้องยืนยันรายชื่อคู่ 2/ตำแหน่งผัง ก่อนแก้ตารางแข่งหรือเผยแพร่เป็นฉบับรับรอง.
- คู่ที่ 9 ของเซปักตะกร้อใน 41 หน้าและ JSON มีอยู่เพียงรายการเดียวแล้ว; ห้ามลบรายการจริงจนเหลือศูนย์.
- ภาคผนวก PDF V3 ที่ฝังใน 155 หน้าใช้เป็นหลักฐานเก่า ต้องคงเดิมหรือใส่ป้ายอ้างอิงฉบับแก้แทนการลบ/เขียนทับหลักฐาน.
- ไม่เพิ่มผลแข่งขัน ผู้ชนะ คะแนน วันเวลา และไม่เปลี่ยนจำนวนรายการ 236 ที่ผู้จัดยืนยัน.

## ขั้นดำเนินงาน

1. เก็บแผนนี้ใน branch แยก **ก่อนแก้เอกสาร**; ตรวจ `main` + PR เปิดและขอบเขตขัดแย้ง.
2. จัดทำ **สำเนา PDF 41/155 หน้าเพื่อให้ตรวจร่าง** พร้อมแก้จุดชัดเจนและบันทึกข้อขัดแย้งที่ยังต้องตรวจ; ไม่เขียนทับ PDF ต้นฉบับ, V2/V3 SHA-pinned, พิกัดไฮไลต์, แอป/ผล/Sheets.
3. หากต้องปรับ JSON ใน PR แยก **ต้องรักษา `source_*` ต้นฉบับ** และใส่ข้อมูลแก้ไขในฟิลด์เสนอ/รับรองที่มีหลักฐาน; ห้ามเปลี่ยน public site ก่อน Merge และ QA.
4. QA PDF นับหน้าคงเดิม (41/155), A4, พิกัดข้อความที่แก้, ไม่มีข้อความทับ/ตกหล่น; ตรวจ 236 รายการและเลขคู่ซ้ำอย่างน้อยรายการกีฬาเกี่ยวข้อง.
5. อัปโหลด **ไฟล์ใหม่เพื่อให้ตรวจร่าง** เข้า Drive โฟลเดอร์สูจิบัตร ตรวจลิงก์และขนาดอีกครั้ง.
6. เปิด PR ให้ผู้จัดตรวจ; **ไม่ Merge/สลับเว็บไซต์จนผู้จัดอนุญาต** และต้องทดสอบ Safari/LINE/Chrome หากจะเผยแพร่จริง.
