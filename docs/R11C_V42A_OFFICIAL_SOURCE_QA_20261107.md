# R11C-V42-A — ตรวจคืนรายละเอียดประกาศจากต้นฉบับ

สถานะ: **V42-A draft generated for review; ไม่ใช่ประกาศ/คำสั่งที่รับรอง**

## สาเหตุที่แก้

V4.1 ใช้ notice(read_source(pdf,6),read_source(pdf,16)) ซึ่งเลือกเฉพาะคำนำหน้าประกาศและข้อความปิด ทำให้รายละเอียดจริงของหมวดกรรมการ 1–20 และถ้อยคำ “มีหน้าที่” ตลอดหน้า 6–15 ไม่ครบในหมวดทางการ แม้ตารางรายชื่อกรรมการ 250 แถวจะอยู่ภายหลังแล้วก็ตาม

## แนวทางใหม่

- scripts/docs/v42_official.py: ถอดข้อความจาก **PDF V3 ฉบับที่ builder ตรวจ SHA ผ่าน** หน้า 6–16 โดยเก็บเป็น 11 source-page objects
- แยกหมายเลขหน้าในต้นฉบับออกจากเนื้อหา แต่ทุกบรรทัดที่เหลือมี stable source-line ID, source page, ประเภทแถว (section, member, duty, closing ฯลฯ), พร้อม SHA-256 ของข้อความรายหน้า
- จัดใหม่ด้วยฟอนต์ทางการ Sarabun แบบมีหัว จาก pipeline V4.1 โดยยังคงข้อความครบ ไม่บังคับย่อหรือเลือกเฉพาะคำนำ/คำสั่งท้าย
- แสดงร่างต้นฉบับหน้า 6–16 **ครบทุกบรรทัด** ก่อนทะเบียนรายชื่อกรรมการที่แก้สะกด R19K; ทั้งสองชุดมีจุดประสงค์คนละแบบและติดป้าย “ร่าง/รอตรวจ” ไม่ได้สื่อว่าเป็นคำสั่งลงนาม
- สร้าง souvenir-v42a-official-source-qa.json เป็นผลตรวจ source text → HTML ไม่ให้บรรทัดตกหล่น/ซ้ำ และแสดงจำนวนหมวด 1–20
- เก็บ source hashes และ page-map จาก PDF สร้างจริงสำหรับตรวจภายหลัง; ไม่ใช้เลขหน้า V2/V3 แบบ offset

## งานที่ยังต้องตรวจ/ข้อสังเกต

1. **ประเภทเอกสาร:** V3 หน้า 6 เปิดด้วยคำว่า “ประกาศ” แต่หน้า 16 ปิดด้วย “สั่ง ณ วันที่” ต้องยืนยันฉบับทางการก่อนเผยแพร่
2. **วันและผู้ลงนาม:** ต้นฉบับมีวันที่/ชื่อผู้ลงนามในข้อความร่าง เราแสดงตามต้นฉบับและติดป้ายร่างชัด ไม่ถือว่าการลงนามเกิดขึ้นแล้ว ไม่แต่งเลขประกาศหรือลายเซ็น
3. **ชื่อและเลขข้อ:** อาจมีรายการซ้ำหรือสะกดต่างกันระหว่าง PDF V3 ฉบับแก้และทะเบียน R19K ต้องใช้ทะเบียนฉบับแก้สะกดเป็นฐานตรวจชื่อ และไม่ปรับข้อความต้นฉบับเงียบ ๆ
4. **ความซ้ำในเนื้อหา:** ข้อความประกาศต้นฉบับและตารางกรรมการแสดงคู่กันเพื่อให้ตรวจครบในรอบ A; การลดการซ้ำเชิงรูปเล่มให้ทำในขั้น refinement หลังตรวจ source-to-row coverage
5. **ภาคต่อ V42-B–F:** ยังไม่แก้กำหนดการ กติกา Match Day ผังสาย หรือภาคผนวก V3 ตามแผน V4.2
6. **ความปลอดภัย:** ไม่เผยแพร่ข้อมูลนักกีฬา, ไม่แก้ source/reader หน้าเว็บ, ไม่เปลี่ยน V2/V3 ที่ใช้งานอยู่
