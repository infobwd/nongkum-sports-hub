## รายการที่ไม่แก้เอง — รอยืนยันสถานศึกษา
- **บ้านเสาหงส์:** นางสุธันยชนก/สุธันย์ชนก ทรัพย์ย้อย (คำนำหน้าและสะกดชื่อจริงต้องยืนยันปัจจุบัน); นางสาวอรทัย น้อมแนบ (ไม่พบในชีตครู 74)
- **วัดทุ่งมะสัง:** นางสาวทิพรัตน์ พุ่มเนียม (ไม่พบในชีตครู 74); ชื่อ ศุภนาฏ/ศิริภนาฎ ศิริคงคา ในทะเบียนคล้ายกัน อาจเป็นคนละคน ห้ามรวมอัตโนมัติ
- **บ้านพุพรหม:** วิจิตรตรา โรจน์วัฒนดิลก/โรจนวัฒนดิลก (ทะเบียนยังรอยืนยัน)
- **บ้านหนองกระทุ่ม:** ชื่อ ณรัชช์อร รู้ประมาณ/รูป้ ระมาณ (ข้อความต้นฉบับผิดปกติ ตรวจชื่อก่อนแก้)
- **วังเขาแก้ว:** สังกัดนายภูมิภัทรใน PDF หน้า 12 ใช้ “บ้านเขาแก้ว” แต่หน้า 15 ใช้ “วังเขาแก้ว” ให้โรงเรียนยืนยันชื่อสังกัด
- **บ้านรางขาม / วัดทุ่งมะสัง:** ข้อมูลผู้รักษาการ รร.บ้านรางขามใน PDF กับชีต รร.บ้านรางขามไม่สอดคล้องกัน ต้องยืนยันคำสั่งปัจจุบัน

## ควบคุมความเสี่ยง
- ไม่ปรับชนิดกีฬา คะแนนการแข่งขัน ตารางแข่ง ลิงก์ LINE หรือ `data/public-results.json`
- ไม่ใช้ชื่อที่คล้ายกันตัดสินสถานะการย้าย; ไม่เปลี่ยนสังกัดหรือ `teacher_id` อัตโนมัติ
- บริการหน้า `committee.html` ยังเป็น **รายชื่อร่างเพื่อให้โรงเรียนตรวจ**; ตัวเลขแต่งตั้งรับรองยัง **0**
- R19-D encrypted bundle ยังเก็บ snapshot ก่อนแก้ไว้เพื่อ audit; ผู้ใช้ผ่านรหัสโรงเรียนใหม่จะได้ข้อมูลล่าสุดจาก public projection แต่ช่องทางรหัสเดิมอาจเห็นข้อความเดิมจนกว่าจะ regenerate bundle ที่มีสิทธิ์
- ไม่อ้างว่าโรงเรียนยืนยันทั้งชุดแล้ว; ต้องมีชื่อผู้รับรองและวันที่ในชีต/ช่องทางตรวจตามขั้นตอนเดิม
