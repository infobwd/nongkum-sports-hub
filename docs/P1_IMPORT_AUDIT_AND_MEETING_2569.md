## 3. ไฟล์ข้อมูลและความปลอดภัย

- `data/draft-schedule.json`: 236 การ์ดรายการ (186 คู่ + 50 กรีฑา), 289 แถวลู่ และทะเบียนครอบคลุมทุกหน้า `page_inventory`
- `data/competition-divisions-2569-draft.json`: 33 รุ่น/ประเภท + 177 รายการทีมที่อยู่ในผังจับสาย/คู่จากหน้า 1–6
- ทุกแถวเป็น `draft`, ทุก `date=null`, `all_data_approved=false`
- แหล่งอ้างอิงภายในแถวมี `source_page` และเลขคู่/รายการตามต้นฉบับ
- ใช้ ID ไม่ซ้ำต่อหนึ่งรายการ แม้เลขคู่/เลขรายการในเอกสารพิมพ์ซ้ำ
- พัฒนาเว็บให้อ่าน `source_team_*_label` เมื่อรอผลคู่ก่อนหน้า และอ่าน `lanes` เมื่อเป็นกรีฑา
- **ยังไม่มี Google Sheets หรือช่องทางแก้ไขสาธารณะ**; เป็นขั้นตอน P2
- เก็บแบบนักกีฬาและแบบคะแนนว่างไว้เป็นทะเบียนอ้างอิง ไม่จัดเก็บชื่อเด็กจากเอกสารในไฟล์ JSON สาธารณะ
