# R5 — ใบบันทึกผลและการ์ดมือถือ (มิตรภาพเกม 2569)

สถานะ: ดำเนินการในสาขา R5 และต้องทดสอบเครื่องพิมพ์จริงก่อนใช้งานสนาม

## P0 — กันข้อมูลคู่แข่งขันผิดชนิดกีฬา

ปัญหาจากภาพ iPhone: แบบฟอร์มที่ผู้ใช้เลือกเป็นวอลเลย์บอล แต่รหัสคู่และโรงเรียนยังมาจากเปตอง

- เมื่อเปิดจากหน้าโปรแกรมด้วยรหัส fixture ระบบอ่านข้อมูลจริงจากสูจิบัตรและล็อกชนิดกีฬา รหัสคู่ รุ่น รอบ หน้า PDF ชื่อโรงเรียน และเวลาใน PDF
- ข้อมูลโหลดไม่ได้/รหัสไม่พบ/ชนิดกีฬาไม่ตรง: ระงับปุ่มพิมพ์ และมี print guard สำหรับการพิมพ์จากเมนูเบราว์เซอร์
- ปุ่ม "เริ่มแบบเปล่าใหม่" จะล้างข้อมูลอ้างอิงและคะแนนเดิมทั้งหมด แล้วให้เลือกกีฬาใหม่ได้
- แบบเปล่าจะไม่สร้างรหัสคู่เอง ผู้ใช้ต้องเขียนรหัสที่ตรวจสอบแล้วบนกระดาษ หรือเปิดจากหน้าโปรแกรม
- แยกเวลาใน PDF (อ้างอิง) จากเวลาแข่งขันจริง โดยช่องเวลาแข่งขันจริง **เริ่มว่างเสมอ** ไม่คัดลอกจากข้อมูลที่ยังรอยืนยัน

## P1 — บันทึกคะแนนเฉพาะกีฬาและพิมพ์ A4

| กีฬา | รูปแบบ |
| --- | --- |
| ฟุตบอล / ฟุตซอล | คะแนนช่วงการแข่งขันและรวม พร้อมบรรทัดจุดโทษเมื่อใช้ตัดสิน |
| ยิงจุดโทษ | จำนวนครั้งที่ยิง จำนวนที่เข้า และหมายเหตุ ไม่กำหนดจำนวนครั้งล่วงหน้า |
| เปตอง | คะแนนเกมทีม A/B และหมายเหตุเกมเพิ่มเติม ไม่ใช้หัวข้อครึ่งแรก/ครึ่งหลัง |
| วอลเลย์บอล / ตะกร้อ / เทเบิลเทนนิส | คะแนนเกม/เซ็ตและจำนวนที่ชนะ กรอกเฉพาะเซ็ตที่แข่งขัน |
| ชักเย่อ | ผลชนะ–แพ้และผลแต่ละยก |
| กรีฑา | ลู่ โรงเรียน สถิติ หน่วย อันดับ และหมายเหตุ |

มีช่องรหัสรายการ วัน เวลาแข่งขันจริง สนาม/สนามย่อย อ้างอิงสูจิบัตร และลายเซ็นผู้บันทึก ผู้ตรวจ ผู้รับรองครบ 3 ฝ่าย

ปรับ CSS สำหรับพิมพ์ A4 ให้กระชับขึ้นและป้องกันการพิมพ์รายการที่ตรวจไม่ผ่าน การรับรองว่าทุกชนิดกีฬา **พิมพ์พอดี 1 หน้า A4 จริง** ต้องตรวจบน Safari/Chrome และเครื่องพิมพ์หลังเผยแพร่ ยังไม่มีหลักฐาน Visual QA บนเครื่องจริง

## P2 — ปรับมือถือ

- ย้ายปุ่มแชร์คู่แข่งขันขึ้นหัวการ์ด (ข้างเลขคู่) และย้ายปุ่มแชร์ผลรับรองขึ้นหัวการ์ดผล
- ใช้ aria-label และพื้นที่แตะอย่างน้อย 44×44px
- เก็บ PDF/QA/พิมพ์ใบบันทึกอยู่ในรายละเอียดตามเดิม
- ตัดข้อความ "ยังไม่มีผลรับรอง" ที่ซ้ำใต้ผล 0 รายการ
- ย่อข้อความตรวจไฟล์ล่าสุด แต่ยืนยันว่ารีเฟรชไฟล์เผยแพร่ ไม่ใช่ดึง Google Sheets สด
- ไม่มีผลสมมติหรือการแก้ข้อมูลกีฬา 236 รายการ
