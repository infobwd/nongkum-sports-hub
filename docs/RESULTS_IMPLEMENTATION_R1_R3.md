# มิตรภาพเกม ปี 2569 — R1/R2/R3 แยกโปรแกรมและผลการแข่งขัน

สถานะ: **R1/R2 implemented in GitHub branch; R3 native Google Sheets created, Apps Script installation pending**  
หลักการ: ไม่สร้างผลแข่งขันสมมติ ไม่เปิดเผยผล Draft/Review และไม่เปิดช่องทางเขียนจากเว็บสาธารณะ

## R1 — แยกโค้ดหน้าโปรแกรม (ไม่เปลี่ยนแหล่งข้อมูล)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าโปรแกรมและลิงก์ไปหน้าผล |
| `css/base.css` | สี ฟอนต์ ส่วนหัว และส่วนประกอบร่วม |
| `css/program.css` | การ์ดและตัวกรองของหน้าโปรแกรม |
| `js/shared.js` | ตัวช่วย escape, ช่วงชั้น, จดจำโรงเรียน, URL parameters |
| `js/program.js` | ค้นหาโปรแกรม 186 คู่และกรีฑา 50 รายการตาม PDF (236 รายการ) |

ยังคงแสดงสถานะข้อมูลจาก PDF และข้อมูลเปตองนอกรอบ 24 คู่ที่ยืนยันเฉพาะวัน/สถานที่ โดยเวลาแข่งยังรอแจ้ง

## R2 — หน้า `results.html`

- เมนูนำทาง **โปรแกรมการแข่งขัน | ผลการแข่งขัน** แยกเป็นสองหน้าใน GitHub Pages
- ใช้ตัวกรองโรงเรียน ช่วงชั้น และกีฬา พร้อมรักษา `?school=`, `?sport=`, `?level=` เมื่อสลับหน้า
- `css/results.css`, `js/results.js`, `js/results-renderers.js` — ไม่ทำให้ไฟล์โปรแกรมยาวขึ้น
- รูปแบบการ์ดผลแบ่งตามลักษณะ: **score** (ฟุตบอล/ฟุตซอล/ยิงจุดโทษ), **sets** (เปตอง/วอลเลย์บอล/ตะกร้อ/เทเบิลเทนนิส), **win_loss** (ชักเย่อ), **ranking** (กรีฑา)
- อ่านเฉพาะ `data/public-results.json` ซึ่งเป็นไฟล์ข้อมูลสาธารณะสำหรับผล `approved` เท่านั้น
- ในเวอร์ชันนี้ `public-results.json` มี **0 รายการ** และแสดง “ยังไม่มีผลการแข่งขันที่ผ่านการรับรอง” ไม่ใส่คะแนนปลอม
- `js/results.js` ปฏิเสธไฟล์ที่ schema/metadata/สถานะผลไม่ตรงสัญญา และไม่ render ผล `review` หรือ `draft`
- เมื่อมีผลจริงที่อนุมัติแล้ว ค่อยส่งออกและเผยแพร่หลังผ่านการตรวจซ้ำ

## R3 — Google Sheets แยกบันทึกผลจากโปรแกรม

Google Sheets สำหรับคณะกรรมการเดิมใน Shared Drive `ปี 2569` เปลี่ยนชื่อเป็น **มิตรภาพเกม 2569 — ฐานข้อมูลกรรมการ (โปรแกรมและผลการแข่งขัน)** และมี 8 แท็บ (เดิม 6 แท็บ)

### 07_ผลประเภททีมคู่

`A:S` ทั้งหมด 19 คอลัมน์ ได้แก่ `result_id, fixture_id, sport_id, round, team_a_school_id, team_b_school_id, score_a, score_b, sets_json, winner_school_id, result_status, recorded_by, recorded_at, approved_by, approved_at, evidence_link, revision, correction_note, approval_digest`.

- คอลัมน์ B ใช้ dropdown อ้างอิง `04_คู่แข่งขัน!A2:A187` เพื่อป้องกันรหัสคู่ที่ไม่รู้จัก
- คอลัมน์ K ใช้ `draft / review / approved / corrected`
- กีฬาแบบเซ็ต ให้กรอก `sets_json` เช่น `[{"a":11,"b":6},{"a":11,"b":7}]` (เป็น *ตัวอย่างรูปแบบการกรอกเท่านั้น* ไม่ใช่ผลจริง)
- กีฬาแบบคะแนน ให้กรอก `score_a`, `score_b` เป็นจำนวนเต็มไม่ติดลบ และระบุ `winner_school_id` ให้ตรงผล
- ชักเย่อเก็บผู้ชนะใน `winner_school_id`

### 08_ผลกรีฑา

`A:O` ทั้งหมด 15 คอลัมน์ ได้แก่ `result_id, event_id, school_id, rank, mark, unit, result_status, recorded_by, recorded_at, approved_by, approved_at, evidence_link, revision, correction_note, approval_digest`.

- คอลัมน์ B เป็น dropdown อ้างอิง `03_รายการ!A35:A84` (เฉพาะ 50 รายการกรีฑา)
- บันทึก 1 แถวต่อโรงเรียน/อันดับ (เมื่อมีผลจริง) โดยไม่สร้างชื่อเด็ก/เลขประจำตัวนักเรียนในฐานข้อมูลนี้
- คอลัมน์ G เป็น `draft / review / approved / corrected`
- ตัวส่งออกจะรวมรายการกรีฑาที่ได้รับรองครบชุดเป็นหนึ่งรายการเรียงอันดับ

### กระบวนการอนุมัติและส่งออก

เพิ่ม `apps-script/Results.gs` ให้ใช้งาน **ร่วมกับ** `apps-script/Code.gs` ของ P2:

1. กรรมการที่มีสิทธิ์แก้ไขกรอกผลจริงและแนบหลักฐานภายใน Google Sheets (ไม่เผยแพร่ชื่อผู้บันทึก/หลักฐานส่วนตัวเป็น public JSON)
2. ผู้มีสิทธิ์ใน allowlist `NONGKUM_APPROVER_EMAILS` ตรวจแล้วใช้เมนู **รับรองผลการแข่งขันแถวที่เลือก**
3. Script ตรวจคะแนน/เซ็ต/ผู้ชนะหรืออันดับ พร้อมลงผู้อนุมัติ เวลา และ `SHA-256 approval_digest`
4. ตัวส่งออกตรวจว่าแถวไม่ถูกแก้หลังอนุมัติ และ **คู่แข่งขันหรือรายการกรีฑาต้นทางผ่านการรับรองใน P2 พร้อม digest ที่ถูกต้อง**; ผลกรีฑาที่มีแถวค้างอยู่ในกลุ่มเดียวกันต้องไม่ถูกส่งออกแบบบางส่วน
5. ส่งออกไฟล์เฉพาะข้อมูล approved ลงใน **Drive ส่วนตัว**; ไม่มี API หรือ GitHub token ในหน้าเว็บ
6. ผู้จัดตรวจ JSON อีกครั้งและส่งผ่านกระบวนการเผยแพร่ P3 จึงค่อยนำไปแทน `data/public-results.json` ใน GitHub

> **ยังไม่ได้ติดตั้ง Google Apps Script ลงในไฟล์ Google Sheets จริง:** เจ้าของไฟล์ต้องเปิด **Extensions → Apps Script** และเพิ่มไฟล์ `Code.gs` + `Results.gs` พร้อมตั้ง Script property และสิทธิ์คอลัมน์ผู้อนุมัติ ตามคู่มือ [P2](P2_SHEETS_WORKFLOW.md). การสร้างสองแท็บและตั้งตัวกรอง/การป้องกันบน Google Sheets ทำแล้ว แต่ยังไม่ได้ทดลองรับรองผลจริงเพราะไม่มีผลการแข่งขันที่รับรอง

### ข้อจำกัดและความปลอดภัย

- Google Sheets ยังไม่มีผลการแข่งขันจริงในแท็บ 07/08 และ `public-results.json` ยังคงว่าง
- ข้อมูลโปรแกรมและวัน/สถานที่เปตองที่ยืนยันบางส่วน **ไม่ใช่ผลการแข่งขันที่รับรอง**
- ห้ามเผยแพร่ Google Sheet, ข้อมูลผู้บันทึก, Google Apps Script URL ที่เขียนข้อมูลได้ หรือรหัสลับลงใน Repository
- ไม่สรุปเหรียญหรือคะแนนรวม 5/3/2 จนกรรมการยืนยันหลักเกณฑ์
- ผู้ดูแลต้องตรวจเวอร์ชัน Apps Script/Google Drive permission และใช้ประวัติแก้ไขเมื่อแก้ผลหลังประกาศ
