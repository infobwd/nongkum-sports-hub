# R19-K — ตรวจแก้ชื่อกรรมการสูจิบัตร V3 เทียบทะเบียนครู (6 พ.ย. 2569)

สถานะ: **PLAN FIRST / CORRECTION IN PROGRESS** — ชื่อและสังกัดในสูจิบัตรยังเป็นร่างเพื่อให้โรงเรียนตรวจ

## แหล่งอ้างอิง
- Google Drive: ร่างสูจิบัตรกีฬากลุ่ม ปี 2569 V3 (6 พ.ย.); Google Docs ต้นฉบับอ้างอิง V3
- `data/committee-2569-draft-public-review.json` — เผยแพร่เป็นร่างให้โรงเรียนตรวจ ไม่ใช่คำสั่งแต่งตั้ง
- Google Sheets ทะเบียนครู 8 โรงเรียนจาก `infobwd/sillapa/teacher-verification.html`; สถานะ `รอตรวจ` ไม่ถือว่ายืนยันปัจจุบัน

## ข้อกำหนดการแก้ไข
1. ใช้ชื่อ **นายนพรุจ ลับบัวงาม** ตามผู้จัดยืนยัน; ในชีตบ้านวังด้งมีชื่อเดิมและคอลัมน์ข้อเสนอชื่อที่แก้ถูกต้องแล้ว ต้องรักษาข้อมูลตั้งต้น/รหัสครู
2. แก้เฉพาะชื่อพิมพ์ผิดที่มีหลักฐานสะกดตรงกันข้ามหน้าภายใน PDF หรือทะเบียนที่สอดคล้องสูง; ไม่แก้ชื่อและสังกัดคลุมเครือเอง
3. ก่อนแก้ต้นฉบับ Google Docs และ PDF ให้ทำสำเนาเดิมเก็บย้อนกลับ; ผลแก้ไข PDF ต้องตรวจเลย์เอาต์ก่อนใช้แทนฉบับร่างเดิม
4. รายชื่อรอการยืนยันให้โรงเรียนผู้เกี่ยวข้องตอบรับผ่านช่องทางเดิม `committee-review.html` / LINE; ไม่สร้าง teacher_id หรือรับรองคำสั่งแทนโรงเรียน
5. Public JSON สามารถแสดง spelling correction ตามหลักฐาน แต่ต้องแยกจาก `committee_approved` และห้ามเพิ่มข้อมูลทะเบียนครู/ติดต่อส่วนตัวลง GitHub
