## ปรับปรุง R11D.1 — สำหรับคุณครูใช้มือถือ (4 พ.ย. 2569)

- **เริ่มใช้งาน:** เลือกโรงเรียน → เลือกกีฬา → ดูคู่แข่งขัน. ช่วงชั้น, ค้นหา, รายการที่ควรตรวจซ้ำอยู่ใน “ค้นหาและตัวเลือกเพิ่มเติม” ซึ่งปิดไว้ก่อน
- **ประสิทธิภาพ:** เริ่มแสดง 8 การ์ด กด `ดูเพิ่มอีก 8 รายการ` แบบต่อท้ายไม่สร้างการ์ดเดิมซ้ำ; ค้นหาหน่วง 280ms หลังหยุดพิมพ์ รองรับ composition ของภาษาไทย; ละเว้นการวาดใหม่หากตัวกรองเดิมไม่เปลี่ยน
- **การ์ดแบบย่อ:** วัน/เวลา/สนามและทีมยังเห็นทันที; หมายเหตุ, รหัสและการเทียบฉบับก่อนอยู่ใต้ “ดูรายละเอียดเพิ่มเติม”; ชื่อปุ่มหลัก “แจ้งข้อมูลไม่ตรง” เพื่อคัดลอกข้อความส่งผู้จัดในแชท
- **ภาษา:** ไม่แสดง Revision, Fixture ID, QA หรือรหัส R11D ในเนื้อหาปกติ. ข้อมูลเลข revision/rหัสรายการยังอยู่ในข้อความแจ้งแก้และใต้รายละเอียดสำหรับผู้ดูแล เพื่อไม่ทำลาย audit trail
- **PDF ที่ผู้จัดระบุ:** [ร่าง - สูจิบัตรกีฬากลุ่ม ปี 2569_V2.pdf](https://drive.google.com/file/d/1zMxnF99lJHTQ8zgCH1QUs5rB9Uf8O4IO/view?usp=drivesdk) — พบไฟล์จริงในโฟลเดอร์ Drive ของผู้จัด, ขนาด 982,844 ไบต์, เพิ่มปุ่มเปิดดู/ดาวน์โหลดจาก Google Drive โดย **ไม่ได้คัดลอกไฟล์ลง public repo และไม่ได้เปลี่ยนสิทธิ์แชร์**. การเปิดดู/ดาวน์โหลดจาก Drive ขึ้นกับสิทธิ์ของแต่ละผู้ใช้; หากไม่สามารถเปิดได้ให้ผู้จัดตรวจการแชร์ก่อนส่งให้โรงเรียน
- **หมายเหตุสำคัญ:** ปุ่ม PDF V2 เป็นทางไปดูต้นฉบับประกอบ. หน้ารายการยังอ่าน JSON `program-from-pdf-2569-20261104-draft.json` (ตาม R11A) ไม่ได้เปลี่ยนให้โหลดตารางจาก PDF V2. **ยังไม่รับรองว่าไฟล์ PDF V2 และ JSON ที่ใช้บนเว็บตรงกันทุกแถว**; หากแตกต่างให้บันทึกข้อเสนอแก้
- **Safe Area:** ใช้ meta status bar แบบปกติและ nav ที่ active บนหน้า review; ไม่เพิ่ม fixed header/overlay ทับการเลื่อน, ต้องทดสอบ Safari และ LINE WebView จริงเพื่อปิดประเด็นภาพสถานะ iPhone

ชุดทดสอบเพิ่ม `node scripts/ux/test-review-r11d1.mjs` ครอบคลุมการแสดง 8 รายการ, incremental append, debounce/Thai IME, ค้นชื่อกีฬาภาษาไทยและเลขคู่, ลิงก์ Drive จริง และการไม่ทำ write request.

## 1. การเปิดใช้งาน

1. เปิดเว็บโปรแกรมการแข่งขันตามเดิม `index.html` และเลือกปุ่ม **เปิดหน้าตรวจสูจิบัตรล่าสุด · 237 รายการ** หรือเปิด `review.html` โดยตรง
2. หน้าใหม่มี 187 คู่ + 50 กรีฑา 289 ลู่ พร้อมธง QA 70 รายการ ข้อมูลเป็น draft ตาม PDF ฉบับ 4 พ.ย. 2569; หน้าเว็บหลักยังคง 236 รายการ
3. เลือกโรงเรียน (8 แห่ง) และกีฬา (9 หมวด) หรือช่วงชั้น แล้วค้นชื่อทีม/รุ่น/เลขคู่; หากกำลังตรวจปัญหาให้เลือก **แสดงเฉพาะรายการมี QA**
4. เปิดรายการที่ต้องแก้ กด **คัดลอกข้อมูลแจ้งแก้ไข** แล้ววางในแชทกับผู้จัด พร้อมกรอก `จุดที่พบว่าผิด`, `ข้อมูลที่ถูกต้อง` และ `หลักฐาน/คำยืนยันจากผู้จัด`. ปุ่ม **คัดลอกลิงก์รายการ** สร้าง URL `review.html?fixture=<fixture_id>` ให้ผู้อื่นตรวจจุดเดียวกันได้
5. **ไม่มี R11B ในรอบนี้**: ไม่มีการล็อกอิน ยืนยัน/รับรอง หรือเขียน Google Sheets; การแก้จริงทำจากคำสั่งในแชทโดยตรวจ source และเปลี่ยน GitHub ผ่าน PR ที่ตรวจสอบย้อนหลังได้

## 2. อ่านวัน เวลา และสถานะให้ถูกต้อง

- ช่อง **วันตาม PDF / เวลาตาม PDF / สนามตาม PDF** หมายถึงตัวอักษรที่พิมพ์ใน PDF ไม่ได้ยืนยันว่าใช้แข่งจริง; หากต้นฉบับพิมพ์ `17 พ.ย. 68` ระบบต้องแสดงตามนั้นและมี QA
- เปตองนอกรอบ 24 รายการแสดงกล่อง **ยืนยันเฉพาะวันและสถานที่นอกรอบ**: 12–13 พ.ย. 2569 ที่โรงเรียนบ้านหนองกระทุ่ม ส่วนเวลา/สนามรายคู่จาก PDF ยังรอยืนยัน
- รายการที่คู่แข่งขันเป็น `ผู้ชนะคู่ที่...` จะไม่ผูกโรงเรียนโดยการเดาผู้ชนะ จึงอาจไม่ติดผลลัพธ์เมื่อเลือกตัวกรองโรงเรียน แม้รอบนั้นในอนาคตจะมีโรงเรียนดังกล่าวเข้าชิง
- กรีฑาระบุแถวลู่ตาม PDF, `ศูนย์ฯ` หรือแถวว่างยังคงตามต้นฉบับ ไม่เดาโรงเรียน
- `QA flags` อธิบายจุดที่กรรมการควรตรวจเพิ่มเติม ไม่ใช่ข้อสรุปว่า PDF ผิดทั้งหมด; ดู [R11A](R11A_RECONCILIATION_2569.md)
