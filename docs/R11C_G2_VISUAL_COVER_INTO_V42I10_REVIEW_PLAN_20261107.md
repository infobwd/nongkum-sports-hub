# R11C — แผนรวมปกที่ผู้จัดเลือกลงเล่ม PDF ตรวจร่าง (7 พฤศจิกายน 2569)

**สถานะเริ่มต้น:** PLAN RECORDED BEFORE PDF EDIT / NOT MERGED / REVIEW-ONLY

## หลักฐานและฐานข้อมูล

- ภาพปกล่าสุดที่สร้างให้ผู้จัดในแชทหลังการปฏิเสธปก PDF รอบก่อน ถูกสั่งให้นำลงเล่มโดยผู้จัด (เป็นคนละ proof กับ PR #117 ที่ REJECTED)
- ใช้ PDF สูจิบัตร V42-I10 ที่ส่งเข้า Google Drive แล้ว ขนาด 155 หน้า เป็น **review base**; PR #116 ยังคงเป็น draft/open ไม่ใช่แหล่งอนุมัติเผยแพร่ และห้ามแปลความว่าได้ Merge แล้ว
- ปกใหม่แทน **เฉพาะหน้า 1** ไม่ต่อหน้าปกใหม่เพิ่ม; หน้า 2–155 ต้องคงเนื้อหา/ลำดับ/ผลการเรนเดอร์เดิม
- ให้เก็บ PDF รุ่นใหม่ในโฟลเดอร์สูจิบัตร Drive แยกชื่อรุ่น; ไม่ทับต้นฉบับหรือเล่มก่อน ไม่แตะเว็บ/Google Docs/JSON/ผลคะแนน
- ภาพงานกราฟิกต้นแบบและ PDF ที่มีภาพนักเรียนเก็บใน Drive แบบจำกัดสิทธิ์ ไม่ commit ลง public repository
- รักษา internal outline/bookmark/page jump ของเล่มเดิมให้มากที่สุด; ตรวจ A4, จำนวนหน้า, ข้อความสำคัญ, ส่วนประกาศ 11 หน้า, 236 รายการ, 250 กรรมการ, 486 anchors และภาคผนวก V3 โดยไม่กล่าวว่าผ่านการตรวจข้อมูลทางการ
- ปกภาพที่ผู้จัดเลือกเป็นภาพรวมสำเร็จรูป (raster) จึงอาจไม่ค้นหาหรือแก้ไขตัวอักษรบนหน้า 1 ได้เทียบกับ native PDF เดิม; ปรับปรุงชั้นข้อความประกอบเพื่อการค้นหาได้หากทดสอบแล้วไม่บิดเบือนภาษาไทย
- ข้อจำกัดสำคัญ: ไฟล์ภาพต้นฉบับ 1055×1491 px ประมาณ 127.5 dpi เมื่อเต็ม A4, ต้องทดสอบพิมพ์จริง; สิทธิ์ภาพบุคคล/เด็กและ R11E ทางการ **ยังไม่อนุมัติ** แยกจากคำสั่งให้รวมเล่มร่าง

## ขั้นตอนตามลำดับ

1. บันทึกแผนนี้ลง GitHub branch แยกก่อนแก้ PDF
2. อ่านเมทาดาทาและจุดอ้างอิงของฐาน 155 หน้าใน Drive; สร้างหน้า A4 จากภาพปกล่าสุด
3. แทนหน้า 1 โดยไม่รบกวนหน้า 2–155; เก็บ outline และ page mapping
4. QA: page count, page dimension, cover render, text parity/page render checks (โดยเฉพาะประกาศ PR82), bookmark parity, hash รุ่นก่อน/ใหม่ และข้อจำกัดการสกัดข้อความไทย
5. อัปโหลด PDF review รุ่นใหม่เข้า Drive และ readback ชื่อ ขนาด MIME โฟลเดอร์/URL
6. บันทึกผลตรวจพร้อมหลักฐานใน GitHub PR สำหรับ audit (ยังไม่ Merge และไม่ publish)

- PR #116 และ PR #117 ยังคงเปิดเป็น Draft โดยไม่แตะ source/PDF ของสายงานนั้น
- ห้ามใช้คำว่า 'official', 'publish' หรือ 'approved results' กับไฟล์นี้
