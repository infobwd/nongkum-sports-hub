## 2. มาตรฐานออกแบบที่ใช้

- ปกกราฟิกใหม่สีกรมท่า–ทอง ไม่คัดลอกภาพต้นแบบหรือโลโก้โรงเรียน
- เนื้อหา: หน้า A4 แนวตั้ง, ตารางสนาม A4 แนวนอน; มีสารบัญคลิกได้พร้อมเลขหน้าจริง, Bookmarks, Explicit GoTo และลิงก์กลับสารบัญ (ในสูจิบัตร)
- ใช้ Noto Sans Thai + Waree ตามหน้าที่ (ไม่บังคับ Sarabun); ฟอนต์ที่ใช้จริงฝังใน PDF แบบ subset, ไม่แนบ raw font
- คงข้อมูล DRAFT/รอตรวจ; ไม่มีคะแนน/อันดับ/ผู้ชนะที่สร้างขึ้นเอง

## 4. ข้อสังเกตและการตรวจรับที่ยังค้าง

- **ต้นฉบับกรีฑาเลข 35 และ 48 ซ้ำอย่างละสองครั้ง** (รวม 50 รายการ) ยังไม่มีเลข 49/50; ไม่เปลี่ยนเลขเอง
- **ข้อมูล PR #137** เป็นรายงานผู้เข้าชิง ไม่ใช่ผลคะแนน; บางเลขคู่ใน Google Sheets กับ PDF ไม่ตรงกัน; ห้ามเติมคู่แข่งหรือผลสมมติ
- **ยังไม่ทดสอบกับเครื่องพิมพ์ A4 จริง** / Safari iOS / Chrome Android / LINE WebView / สิทธิ์คนภายนอก Google Drive
- **ตรวจภาพภาษาไทยผ่าน** แต่ยังไม่ได้ตรวจ round-trip คัดลอกอักษรไทยทุกตัวทุกหน้าแบบ 100%; Unicode บางแบบใช้รูปนฤคหิต+สระอาแทนสระอำเพื่อความถูกต้องในการจัดรูปและการคัดลอก ตรวจให้ครบก่อนเผยแพร่
- ยังไม่ได้ทำ crosswalk รายการต่อรายการเทียบ Google Sheets ปัจจุบันและหลักฐานรับรองทั้งหมด; ฉบับนี้ห้ามระบุว่าเป็นเอกสารการแข่งขันรับรองทางการ

## 5. ป้องกันปัญหาฟอนต์หลุดซ้ำ

1. สร้าง PDF ใหม่จาก HTML/CSS เป็นแหล่งเดียว ไม่แก้ข้อความโดยวางฟอนต์อื่นทับ PDF
2. กำหนด font roles ใน CSS โดยบทบาท, ไม่กำหนด Sarabun เป็นฟอนต์หลักแบบไม่มีหลักฐาน และไม่ใช้กฎ WD Media มาแทนต้นแบบกีฬา
3. หลัง PDF build ตรวจ embedded font names, spans, page dimensions, link annotations, และ render ทุกหน้า 150–200 DPI
4. ห้าม Merge/เผยแพร่จนผู้จัดตรวจรับรายการกีฬา/วันเวลา/สนามจริง, A4 print, และมือถือ/LINE
