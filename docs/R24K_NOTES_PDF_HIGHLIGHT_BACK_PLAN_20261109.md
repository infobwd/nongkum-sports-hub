## ขอบเขตที่ได้รับอนุญาตในรอบนี้ (K1)
1. คลิกจากการ์ดข้อสังเกตไป `pdf-viewer.html?page=<p>&note=<id>` โดย **หน้าและ note ID ที่ whitelist**; ปุ่มด้านบนอ่านว่า **“← กลับไปข้อสังเกตเดิม”** และลิงก์ตรงไป `booklet-notes.html?note=<id>#note-<id>` ไม่พึ่ง browser history. เมื่อข้อมูลโหลดเสร็จให้เลื่อนไปการ์ดเดิมและเน้นตำแหน่งหัวข้อ.
2. สร้างรายการ **แถวอ้างอิงที่ตรวจพิกัดแล้ว** ต่อประเด็นโดยใช้ `fixture.id` ที่มีอยู่จริงใน `data/program-pdf-positions-v2.json`; ตรวจ source PDF SHA, index 236 รายการ, หน้า, กีฬา, เลขคู่ และสิทธิ์สถานะรายการ active. ห้ามคาดเดาค่าพิกัดหรือสร้างคู่ใหม่.
3. แสดงกรอบสีตรงแถวของคู่/หัวข้อกรีฑาที่เกี่ยวข้อง พร้อมตัวเลือก “จุดก่อนหน้า / จุดถัดไป” สำหรับเรื่องที่มีหลายแถว; เปลี่ยนหน้า/ย่อขยายต้องล้างกรอบเก่าและวางใหม่. สีหมายถึง **ตำแหน่งให้ตรวจ** ไม่ใช่ผลตรวจรับหรือยืนยันว่าแถวนั้นผิด.
4. สำหรับข้อสังเกตที่ยัง **ไม่มีตำแหน่งแถวอ้างอิงที่ตรวจได้** เช่น กติกา/วันที่หัวหน้าเอกสาร/ภาพปก/คำสั่งกรรมการ ให้เปิดหน้าโดยไม่เน้นสีและบอกตรง ๆ ว่า **ยังไม่ได้ระบุตำแหน่งที่แน่นอน**; ห้ามไฮไลท์ผิดแถวเพื่อให้ดูเหมือนครบ.
5. เล่มรวม 155 หน้า: รักษาตัวอ่านเดิม เพิ่มปุ่มกลับการ์ดเดิมแบบ same-origin และป้ายว่า **ยังไม่มีตำแหน่งข้อสังเกตที่ตรวจรับสำหรับเล่มรวม จึงยังไม่เน้นสีและไม่กระโดดหน้าเอง**. **ไม่แก้พิกัด PDF 155 หน้าในรอบนี้**.
6. ลดการซ้ำข้อความ “สิ่งที่พบ” โดยแสดง “จุดที่ต้องตรวจ 1, 2...” เมื่อมีมากกว่า 1 ข้อ และยังคงภาษาไทยทั่วไป.
7. แยกงานจาก PR #124 ด้วย helper ใหม่สำหรับ mapping/highlight, เพิ่ม hook เฉพาะจุดใน `js/pdf-viewer.js` และ rebase/ตรวจ conflict ก่อน Merge; ไม่แก้ PDF.js version/module path ของ PR #124.
