# มิตรภาพเกมส์ 2569 — สูจิบัตร R29 (ฉบับตรวจร่าง)

เวอร์ชัน: `R29-DRAFT-20261115` · **ไม่ใช่ฉบับรับรองและยังไม่ได้ Merge / เผยแพร่เว็บไซต์**

## ต้นแบบและหลักการออกแบบ

ศึกษาไฟล์จริง [รายงานผู้บริหารศิลปหัตถกรรมนักเรียนครั้งที่ 74, PDF 23 หน้า](https://drive.google.com/file/d/1WUCQzsH3uySADdY_YYfN-l7do3CLFyv_/view) แล้วเลือกใช้แนวทาง: ปกแบบนิตยสาร, พาดหัวเล็ก (eyebrow), โทนกรมท่า–ทอง, กล่องสรุป, ตารางกระดาษสะอาด, สารบัญพร้อมเลขหน้าจริง, ลิงก์ในเอกสารและ Bookmarks. **ไม่คัดลอกหน้า/ลวดลาย/โลโก้/ไฟล์ฟอนต์จากต้นฉบับ.**

ไม่บังคับ Sarabun และไม่ใช้กฎ WD Media Production Loop แทนความเหมาะสมของงานกีฬา. ตระกูลที่ใช้อ้างอิงในงานใหม่คือ **Noto Sans Thai** สำหรับข้อความสำคัญและตาราง, **Waree** สำหรับป้ายตกแต่งขนาดเล็ก/บทบาทรอง พร้อม fallback ของระบบตามต้องใช้ ไม่ให้สลับฟอนต์เฉพาะตัวอักษรที่แก้หลังสร้าง PDF.

## ไฟล์

- `program-data.json` — ข้อมูลร่าง 186 คู่ + 50 กรีฑา (289 ลู่) จาก PDF R28 41 หน้า และการแก้ R27-C; แยกจากผลรับรอง
- `mittraphap-2569-r29-booklet-DRAFT.html` / `booklet.css` — ต้นฉบับสูจิบัตร A4 แนวตั้ง
- `mittraphap-2569-r29-field-DRAFT.html` / `field.css` — ต้นฉบับตารางสนาม A4 แนวนอน
- `build.py` — สร้าง HTML ที่แก้ไขต่อได้, สร้าง PDF ด้วย WeasyPrint 68.0 และใส่ PDF Bookmarks + Explicit GoTo
- `qa.py` — ตรวจ PDF ที่สร้างแล้ว, ข้อมูล, embedded fonts, ลิงก์, ขนาดกระดาษ, bbox และ render ทุกหน้าที่ 150 DPI
- `parse_program.py` — ตัวช่วยถอดข้อมูล R28 PDF ใหม่ (ต้องตรวจข้อมูลด้วยผู้รับผิดชอบก่อนใช้แทน snapshot)
- `qa-summary.json` / `QA_REPORT.md` — ผลตรวจและข้อจำกัด

**ไม่มีไฟล์ฟอนต์แนบ**; ให้ติดตั้งฟอนต์อย่างถูกสิทธิ์ในเครื่องที่ใช้สร้าง PDF. ชุดสร้างทดสอบในระบบที่มี Noto Sans Thai และ Waree.

## สร้างซ้ำ

```bash
pip install -r requirements.txt
python build.py
python qa.py
```

HTML/PDF จะอยู่ใน `output/`; CSS ถูกคัดลอกเข้า `output/` เพื่อให้เปิด HTML แบบออฟไลน์ได้. เมื่อต้องการแก้ข้อความ ให้แก้ `program-data.json` ที่มีหลักฐานและปรับการจัดหน้าด้วย CSS ก่อนสร้างใหม่ ไม่แก้ PDF ด้วยการวางข้อความคนละฟอนต์ทับ.

การถอดต้นฉบับใหม่ (ไม่แนะนำให้เขียนทับข้อมูลที่ผ่านการตรวจแล้วโดยอัตโนมัติ):

```bash
python parse_program.py --source /path/to/R28_41pages.pdf --output program-data-new-draft.json
```

## ข้อควรตรวจรับ

- ต้นฉบับกรีฑาใช้เลข **35 และ 48 ซ้ำอย่างละสองครั้ง**, ไม่ปรากฏเลข 49/50 แต่รวม 50 รายการ; ยังไม่แก้เลขโดยคาดเดา
- เปตอง 10 ปีชาย คู่ 2 = รางขาม–ทุ่งมะสังฯ; คู่ 10 รอบรองใช้ผู้ชนะคู่ที่ 3 พบ 4 ตาม R27-C
- บัญชี PR #137 รายงานบ้านวังด้งเข้ารอบชิงเปตอง 10 ปีหญิงและ 12 ปีชายเท่านั้น ยังไม่มีคะแนน/คู่แข่งที่รับรอง; คู่ลำดับใน Google Sheets เทียบกับ PDF ยังรอตรวจ
- ต้องตรวจข้อมูลกับ `main` และฉบับรับรองล่าสุดแบบรายการต่อรายการก่อนเผยแพร่; ไฟล์ปัจจุบันสร้างจาก **R28 PDF ฉบับร่าง** ไม่ใช่ผลแข่งขันจริง
- พิมพ์ A4 จริง, เปิด PDF บน Safari/Chrome/LINE, ตรวจสิทธิ์ Drive และตรวจข้อความไทยจากการคัดลอกทุกหน้า ก่อนนำขึ้นเว็บไซต์

## สิทธิ์ฟอนต์

สร้างด้วยฟอนต์ที่ติดตั้งในระบบ (ไม่ดึงออกจาก PDF ต้นแบบ). ข้อมูลลิขสิทธิ์จาก metadata ของแพ็กเกจในเครื่อง: Noto ตระกูล SIL OFL 1.1; Waree (TLWG) มีเงื่อนไขอนุญาตของ Bitstream Vera ตามแฟ้ม `fonts-tlwg-waree-otf/copyright`; อักษรสำรอง Kinnari มี font exception ในแพ็กเกจ TLWG. PDF เก็บฟอนต์ที่ฝังไว้แบบ subset เท่านั้น. **ไม่แจกจ่ายไฟล์ฟอนต์แยกในโฟลเดอร์ต้นฉบับ.**
