## วิธีสร้างซ้ำ

```bash
python build_r30f.py --source R30E_132.pdf --output R30F_44.pdf --workdir work
python qa_r30f.py --source R30E_132.pdf --pdf R30F_44.pdf --out QA_REPORT.json
```
