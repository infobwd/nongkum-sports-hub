# R30-D — ป้องกันสีพื้นและข้อความสนามหลุดในการแก้ตารางเปตอง

วันที่ 15 พฤศจิกายน 2569 • DRAFT • ต่อจาก PR #139 (ยังไม่ Merge)

## สาเหตุที่ตรวจพบจากไฟล์จริง
- R30-B หน้า 64: ชื่อคู่ในคอลัมน์แข่งใช้ Noto-Bold + Waree-Bold 9.7pt สี #122b44, พื้นแถวสี #f6f8f6; สนาม 2 อยู่ x435.8–464.0.
- R30-C หน้า 64: `scripts/r30c/build_r30c_base.py` ใช้แผ่นวางข้อความที่ `Rect(210,277,470,294)` และ `Rect(210,575,470,592)` โดย fill สีขาวและ 11pt #173e60 แทนค่าต้นฉบับ; ช่วง x435–470 ทับสนาม 2. การทดสอบ PDF เดิมตรวจคำที่แก้ แต่ไม่ได้ตรวจเนื้อหาคอลัมน์สนามและความเหมือนของรูปแบบทุกช่อง.
- ผู้จัดสั่งแก้ไขให้พื้นแถว ขนาดฟอนต์ สี และสนามคงเดิม; ห้ามเปลี่ยนข้อมูลคู่ 2 (รางขาม–ทุ่งมะสังฯ) และคู่ 10 (ชนะคู่ 3–4) ที่ยืนยันไว้.

## แนวทางแก้
1. เริ่มจาก R30-C PDF ฉบับตรวจร่างและ R30-B เป็นฐานอ้างอิงแบบ immutable; เลือกเฉพาะพื้นที่แถว 2/10 หน้า 64 และดึงข้อมูลเวกเตอร์/พื้นหลัง/คอลัมน์สนามเดิมจาก R30-B กลับคืน.
2. เปลี่ยนข้อความเฉพาะในกรอบคอลัมน์ชื่อคู่ `x=210..425` ไม่ล้ำไปคอลัมน์สนาม `x>=435`, ไม่เพิ่มขนาดฟอนต์เฉพาะช่อง ใช้รูปแบบ Noto Sans Thai Bold/ Waree Bold 9.7pt สีกรมท่า #122b44 พื้นสี #f6f8f6.
3. ทำเป็นสคริปต์ปรับรุ่น **R30-D** (ไม่ทับ R30-C) และเพิ่ม QA แบบ fail-closed เปรียบเทียบสีพื้น/ฟอนต์/ขนาด/ข้อความสนาม 2/ภาพนอกกรอบ; ออกภาพขยายก่อนหลังและรายงานความต่าง.
4. ตรวจ 94 หน้า, สารบัญ/Bookmarks/ลิงก์ GoTo/QR เดิม, การคัดลอกข้อความไทย, เนื้อหาหน้าอื่นต้องไม่เปลี่ยน. เก็บ PDF, Source และ QA บน Drive และ branch PR #139 เพื่อรอตรวจรับ.
5. **ไม่ Merge/ไม่สลับเว็บ** โดยไม่มีผู้จัดอนุญาตและหลักฐานตรวจรับจริง; เก็บต้นฉบับทุกเวอร์ชัน.
