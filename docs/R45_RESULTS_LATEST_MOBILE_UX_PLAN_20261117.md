- ตรวจ `main` หลัง R44/PR #171 Merge, `results.html`, `js/results.js`, `js/results-source-r32.js`, `js/results-renderers.js`, `css/results.css` และ `css/standings.css`

- PR เปิดค้าง #159 (R40 photo upload), #144 (R33) และงานสูจิบัตร: งานนี้ไม่แก้ไฟล์ระบบภาพ/ฐาน/สูจิบัตร/ตารางแข่งขัน และไม่ปิด PR เดิม

## ขอบเขตตามที่ผู้จัดเห็นชอบ
1. หน้าผลการแข่งขันบนมือถือ: นำลิงก์ภาพกิจกรรมออกจากเมนูย่อยด้านบนที่กำหนดเป็นสองคอลัมน์อยู่แล้ว; คงการเข้าถึงภาพกิจกรรมจากแถบนำทางด้านล่าง
2. โหมดทุกกีฬาและการกรองกีฬา/โรงเรียน/ช่วงชั้น: เรียงเฉพาะผลที่เผยแพร่และรับรองแล้วจากเวลาที่ `published_at` ล่าสุดก่อน รวมกีฬาและรูปแบบผลทั้ง `score`, `sets`, `win_loss`, `ranking`. ผลที่แก้แล้วเผยแพร่ใหม่ต้องขึ้นก่อนตามเวลาเผยแพร่จริง; ไม่ใช้ผลร่าง, `result_date` หรือเวลาที่ผู้ใช้รีเฟรชแทน
3. แสดงเวลาเผยแพร่รายบัตรเมื่อมีข้อมูล live, เก็บลิงก์ตรง/แชร์ LINE/ภาพที่อนุมัติแล้ว/จำนวนรายการ/ตัวกรอง/สถานะผลเดิม
4. ลดความสูงหน้าจอและข้อความจำนวนซ้ำ; ปรับคำสำหรับบุคคลทั่วไปและทำให้รู้ว่าสามารถปัดเลือกกีฬาได้
5. หากใช้ข้อมูลสำรอง ให้ระบุว่าไม่ยืนยันความใหม่และไม่สร้างเวลาของรายรายการขึ้นเอง; คงลำดับเดิมเมื่อไม่มีเวลารายการ

## การดำเนินการและทดสอบ
