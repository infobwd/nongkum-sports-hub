# R44 — แชร์ผลแข่งขัน LINE เป็นข้อความอ่านได้ทันที ครอบคลุมทุกกีฬา

สถานะ: วางแผนแล้ว (สาขา `feat/r44-line-full-approved-result-text-20261117`; ยังไม่ Merge/เผยแพร่/ตรวจรับ)
ต่อยอดจาก R36/R39/R41 — ไม่สร้างเส้นทางแชร์หรือแหล่งข้อมูลผลใหม่

## ข้อมูลที่ตรวจ
- `main` bf8b6cbf04913b180110f82120fd998f1c312a8e; PR ที่เปิดค้างเน้น R40 ภาพและงานตาราง/สูจิบัตร ไม่แก้ `js/shared.js`.
- `public.nongkum_published_results` เป็นผลรับรองที่เผยแพร่; ผล 4 แบบ `score/sets/win_loss/ranking`.
- 9 กีฬาใน `data/public-results.json`: ฟุตบอล, ยิงจุดโทษ, ฟุตซอล, วอลเลย์บอล, เซปักตะกร้อ, เปตอง, เทเบิลเทนนิส, ชักเย่อ, กรีฑา.
- `js/shared.js` ปัจจุบันส่งข้อความทั่วไปเท่านั้น โดยใช้ R36 per-result OG หรือ R41 neutral shortlink สำหรับภาพตัวอย่าง; LINE จึงไม่แสดงรายละเอียดคะแนนในข้อความ.
- `data/public-results.json` เป็นข้อมูลสำรองว่าง; หน้า results ใช้ read-only R32 live feed; ห้ามสร้างผลจากร่าง.

## ขอบเขตและหลักการ
1. สร้างข้อความสำหรับ LINE จากผล `approved` อย่างเดียว: ชื่อกีฬา/รุ่น/ชื่อรายการที่จับคู่ source ได้อย่างถูกต้อง/รอบแข่งขัน/คู่หรืออันดับ/ผลคะแนนหรือเซต/ผู้ชนะเมื่อมีในผล/วันที่แข่งขันที่มีจริง.
2. ข้อความ 4 แบบใช้ตัวสร้างเดียวและใช้กับกีฬา 9 ประเภททั้งหมด ไม่ฝังผลรายกีฬาหรือเดาผล; คงระดับปฐมวัย ประถม มัธยม เพศ รุ่น และการแข่งขันรอบต่าง ๆ ตาม field ที่มีจริง.
3. ส่งข้อความ + ลิงก์ผลล่าสุดเป็น **ข้อความเดียว** ผ่าน Web Share API เพื่อไม่ให้ LINE แสดงเพียง URL โดยไม่มีเนื้อหา; กรณีไม่ได้รองรับ native share คัดลอกข้อความเดียวกันพร้อมลิงก์.
4. คง R36/R41 shortlink และ OG cards โดยไม่แก้ความหมายของผลเดิม; ข้อความแชร์สามารถอัปเดตตาม live approved version. ไม่แก้ส่วนรับรอง, ตารางคะแนน, ผลใน Supabase, ภาพกิจกรรม, กรรมการ หรือสูจิบัตร.
5. แสดงข้อความเฉพาะฟิลด์ที่มีจริง: `win_loss` ไม่มีคะแนนต้องไม่สร้างคะแนน; `sets` แสดงคะแนนรายเซตไม่คำนวณผู้ชนะเอง; `ranking` เรียงอันดับและแสดงเฉพาะสถิติที่มี; `score` เสมอได้เมื่อคะแนนเท่ากันและไม่มีผู้ชนะยืนยัน.
6. URL ที่แชร์ยังเป็นหน้าดูผลรับรองล่าสุด; ไม่รับประกันว่าข้อความที่ถูกส่งไปแล้วจะอัปเดตย้อนหลัง. เปิดบน LINE, iOS Safari, Android Chrome ต้องทดสอบจริงหลัง merge.

## ไฟล์ที่คาดว่าจะเปลี่ยน
- `js/shared.js` — formatter และ native/copy payload เฉพาะผลรับรอง
- `results.html` — อัปเดต version script เพื่อไม่แสดงโค้ด cache เก่า
- `scripts/r36/test-result-share.mjs` — ปรับ assertion native share เดิม + coverage สำหรับข้อความ
- `scripts/r44/test-line-result-text.mjs` — ผลสมมติเฉพาะใน tests: 9 กีฬา × 4 แบบ และ negative cases
- เอกสารนี้ — เกณฑ์ทดสอบและสถานะการดำเนินงาน
