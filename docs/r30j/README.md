# R30-J — สูจิบัตรฉบับรวม พร้อมผลรับรอง

ผลลัพธ์จาก PDF R30-I 48 หน้า (พิธีการ/กรรมการ) + 1 หน้าสารบัญ + PDF R30-E ส่วนผัง/ตารางกีฬา 88 หน้า = 137 หน้า

- `combine_latest_r30i.py`: ตัวจัดเล่ม PDF บนฐานไฟล์ต้นฉบับแบบอ่านอย่างเดียว
- `verify_r30j.py`: ตรวจข้อความต้นฉบับ 136 หน้า, จำนวนหน้า, ลิงก์, bookmarks, การแสดงและคัดลอกภาษาไทย, ภาพ 150 DPI ทุกหน้า
- `R30J_BUILD_REPORT.json` และ `R30J_QA_REPORT.*`: บันทึกอ้างอิง SHA และผลตรวจ
- `toc_competition.html`: HTML หน้าสารบัญการแข่งขัน สร้างด้วย WeasyPrint

การใช้งานในรอบถัดไปต้องนำ PDF ต้นฉบับใน Drive รุ่นที่ระบุมาใส่ตามเส้นทางในสคริปต์ (อาจปรับเส้นทางให้ตรงเครื่อง) และติดตั้ง PyMuPDF, WeasyPrint 68.0, Pillow รวมถึงฟอนต์ไทยที่ได้รับอนุญาต. ไม่รวมไฟล์ฟอนต์ในชุดส่งมอบ.

**DRAFT เท่านั้น** ไม่ใช่ฉบับรับรองผู้จัด ไม่ใช้เล่มนี้เป็นหลักฐานว่าผังหรือรายชื่อกรรมการทั้งหมดได้รับการยืนยันแล้ว.
