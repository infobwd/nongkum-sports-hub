# R35 — ผลรับรอง ตัวกรอง และฟอร์มบันทึกผลบนมือถือ

วันที่เริ่ม: 16 พ.ย. 2569  
Issue: #150 · ต่อจาก R34 (#145) / R32  
สถานะ: พัฒนาในสาขา `feat/r35-results-filters-mobile-entry-20261116` รอ CI, PR, Merge, ตรวจหน้าเว็บจริง

## ข้อมูลต้นทางที่ตรวจแล้ว

- `main` ก่อนงาน: `results.js` รับค่ากรองกีฬา/โรงเรียน/ช่วงชั้นจากการสลับแท็บตารางแข่ง ทำให้ผลรับรองหนึ่งรายการแสดงเป็นศูนย์ได้; หน้าว่างไม่ได้บอกว่าเกิดจากตัวกรอง
- ผลรับรองใน Supabase Meeting `public.nongkum_published_results` มี 1 รายการ (เปตองชาย 12 ปี บ้านวังด้งชนะบ้านเสาหงส์ รุ่นข้อมูล 1); **ไม่เปลี่ยนผลนี้**
- สำเนา `data/public-results.json` ยังมี 0 ผล: ต้องบอกผู้ใช้ตรง ๆ ว่ากำลังใช้สำเนาที่อาจไม่ใช่ล่าสุดหากอ่าน Supabase ไม่สำเร็จ ไม่ให้เห็นข้อความ “ไม่มีผล” ราวกับยืนยันจากฐานล่าสุด
- ภาพ iPhone แสดงหน้ากรองกินพื้นที่มาก ข้อความวันที่ ISO และแบบฟอร์มเซ็ตที่ให้พิมพ์เครื่องหมายเอง; โค้ดเดิมใช้ `result_type` ที่เลือกเองทุกครั้ง
- `docs/R34_CARD_RESULT_EDIT_AND_6H_UNLOCK_PLAN_20261116.md` และ `docs/R32_SUPABASE_MEETING_RESULTS_PLAN_20261115.md` เป็นฐานเดิม ไม่สร้างฐานผลอีกชุด

## ขอบเขตปรับปรุง

1. ลิงก์สลับจากตารางแข่งไปหน้า `results.html` เริ่มที่ผลรับรองทุกกีฬา แต่ URL ผลที่แชร์หรือ filter ที่ระบุชัดยังคงใช้ได้
2. ปุ่ม “ทุกกีฬา” ติดอยู่ซ้ายสุดและไม่หลุดจอ, รายชื่อกีฬาเลื่อนได้, โรงเรียน/ช่วงชั้นอยู่ในตัวเลือกเพิ่มเติมแบบพับได้, แสดงชื่อค่ากรองที่กำลังใช้ + ปุ่มล้าง
3. แสดงจำนวนผลรับรองทั้งหมดและจำนวนที่ตรงตัวกรองแยกกัน; 0 เพราะ filter ≠ 0 เพราะไม่มี approved ≠ 0 เพราะใช้สำเนาเก่า
4. แสดง `metadata.published_at` เป็นวันเวลาไทยใน `Asia/Bangkok` ด้วยเบราว์เซอร์ ไม่แก้ timestamp ฝั่งฐาน
5. ฟอร์ม R34 คงสิทธิ์ 6 ชั่วโมงและกระบวนการส่งผลรอตรวจเหมือนเดิม: ค่าเริ่มต้นตามกีฬา (เซ็ต/คะแนน/ชนะ-แพ้/อันดับ), ยังเลือกชนิดอื่นได้ถ้าข้อมูลจริงกำหนด; เซ็ตมีช่องตัวเลขสองทีมต่อเซ็ตและเพิ่ม/ลบไม่เกิน 7 เซ็ต, กีฬาระบุชื่อไทยจาก approved-only feed ที่ตรวจแล้ว
6. เพิ่มทดสอบอัตโนมัติใน R34 workflow: filter navigation, no-results state, เวลาไทย, default sport, set inputs; คง regression ของ MutationObserver เพื่อป้องกันอาการหน้าเว็บค้าง

## ผลกระทบที่อนุญาต

แตะเฉพาะ `js/navigation.js`, `js/results.js`, `results.html`, `css/results.css`, `js/r34-card-editor.js`, `css/r34-card-editor.css`, `index.html` (อัปเดตเวอร์ชันไฟล์), ชุดทดสอบและ CI; ห้ามแตะฐานข้อมูล R32/R33, token, PIN, ผลรับรอง, สูจิบัตร, การส่งผลรออนุมัติ หรือระบบประชุม
