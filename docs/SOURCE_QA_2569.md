## สถานะการตรวจข้อมูล

- **ยืนยันแล้วจาก PDF เท่านั้น**: โครงสร้างรายการ หมวดกีฬา คู่แข่งขันบางส่วน และเวลาเท่าที่เอกสารระบุ
- **ยังไม่ใช่ตารางที่ผู้จัดประกาศ**: วันแข่งขันจริง, เวลา/สนามที่เว้นว่าง, ทีมในรอบต่อไป, ผลคะแนน, และข้อผิดพลาดที่ระบุข้างต้น
- ข้อมูลทุกแถวที่นำเข้าระยะแรกต้องมี `source_page` และ `review_status=draft`
- **ห้ามใช้ข้อมูลต้นแบบหรือ sample เป็นข้อมูล Approved โดยอัตโนมัติ**

## วิธีตรวจรับร่วมกับผู้จัด

1. เจ้าหน้าที่รับผิดชอบแต่ละกีฬาอ่านตารางจาก PDF เทียบ Sheet ที่นำเข้า (แถวต่อแถว)
2. รับรองรายชื่อโรงเรียนตาม ID กลาง, คู่แข่งขัน, รุ่น, เพศ, สาย และชื่อสนาม
3. เติมวัน/เวลา/สนามตามคำสั่งจัดการแข่งขันฉบับปัจจุบัน; ถ้าเปลี่ยนแปลงให้บันทึกหมายเหตุและเวลาก่อนเผยแพร่
4. แก้ QA-03/05/06/07/08 ตามมติผู้จัด โดยบันทึกเอกสารอ้างอิง ไม่แก้เงียบ
5. กำหนดผู้อนุมัติและล็อกคอลัมน์ที่ผ่านตรวจรับแล้ว
6. Export เฉพาะแถว Approved ไป public JSON แล้วลองค้นหาด้วยมือถือทุกโรงเรียน
7. เก็บ `source_page`, `approved_at`, `publish_revision` เพื่อย้อนตรวจได้
