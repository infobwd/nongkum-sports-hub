## 3. แนวทางปรับโดยไม่ทำข้อมูลหาย

### G2 — ปกตามแบบ Full Photo V2 ที่เคยเลือก
1. แยก `cover_design_selected = full_photo_v2` จาก `rendered_cover = fallback_g1` ใน QA manifest และในเอกสารแผน; อย่าสรุปว่า `cover_style_approved` แปลว่าปกแบบที่เลือกได้ติดเล่มแล้ว
2. ใช้ภาพเฉพาะจากพื้นที่ส่วนตัวที่ตรวจ provenance / ความเหมาะสมใช้ภาพเด็กและสิทธิ์พิมพ์/เผยแพร่จริง. QA local preview ได้ แต่ห้ามอัปโหลดภาพบุคคลเข้า public repo หรือ GitHub Actions artifacts ที่เผยแพร่ต่อผู้ไม่มีสิทธิ์
3. ตรวจภาพแนวตั้งที่เคยใช้ตัวอย่างขนาดประมาณ 1055×1491 px: เมื่อขยายเต็ม A4 จะมี effective resolution ประมาณ 128 dpi จึง **ไม่ใช่ 300dpi print master** ต้องหา high-res source หรือเลือกทางเลือกออกแบบที่ปลอดภัยสำหรับพิมพ์
4. ตรวจการจัดวางสปอร์ตไตเติลและแถบรายละเอียดตาม V2 ไม่ใช่ใช้หน้าพื้นสีน้ำเงิน G1 แล้วถือว่าจบ G2

### N1 — คืนหน้าเปิดประกาศสไตล์ V4.1 แบบ no-loss
1. เพิ่ม `notice()` เดิมที่ใช้สรุปหน้าเปิดจากต้นฉบับจริงเป็นหน้าแรกของหมวดหลังส่วนพิธี, คงสัญลักษณ์ “ร่าง/รอตรวจ”, ไม่สร้างตราครุฑ/ลายเซ็น/เลขคำสั่งใหม่
2. ย้าย `official_full_html()` ไปต่อหลังหน้าเปิดเป็น “รายละเอียดประกาศตามต้นฉบับ V3” และรักษาข้อความ/หมวด/`มีหน้าที่` ทั้ง 341 บรรทัด
3. จัดเอกสารให้คนทั่วไปแยก 3 ชั้น: **หน้าเปิดประกาศ** → **ต้นฉบับรายละเอียดหน้าที่ 20 หมวด** → **ตารางกรรมการสำหรับแต่ละโรงเรียนตรวจชื่อ** (ตารางเป็น working dataset ไม่ใช่ส่วนต้นฉบับที่รับรอง)
4. อย่าทำให้ชื่อ/ตำแหน่งในต้นฉบับ V3 ดูเหมือนถูกแก้และรับรองแล้ว; ถ้าข้อมูลทะเบียนกรรมการต่างจากต้นฉบับ ให้มี source/review flag แทน silently replacing
5. เพิ่ม QA visual snapshot หน้าเปิดประกาศแบบที่ผู้จัดเลือกและ QA source counts. อนุญาตให้จำนวนหน้ารวมเพิ่มจาก 125 ได้ถ้าครบสาระ; ดู diff/page map ใหม่ ไม่ใช้จำนวนหน้า 125 ตายตัว
