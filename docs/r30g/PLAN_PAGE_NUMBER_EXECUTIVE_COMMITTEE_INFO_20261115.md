## การพัฒนา
1. สร้าง R30-G จาก R30-F โดยไม่แก้ต้นฉบับ. แก้เลขต้นฉบับทุกหน้าที่นำมารวมเล่ม โดยทำ **PDF redaction ในแถบ footer เดิม y≈788–805pt เท่านั้น** และตรวจว่าเนื้อหาที่อยู่เหนือแถบไม่เปลี่ยน. ไม่ลบรหัสข้อมูลในตัวตารางจนกว่าจะตรวจต้นทาง.
2. คงเลขหน้าปัจจุบัน `NN / 44` และปุ่ม **กลับสารบัญ**. ตรวจหน้า 1–44 และ text layer ว่าไม่เหลือเลขเก่า/ข้อความ footer R11C-V42H ใน footer (อาจมีในเนื้อหาส่วนหัวฉบับร่างได้).
3. ปรับ **บทสรุปผู้บริหารหน้า 2** ให้เป็น dashboard 8 โรงเรียน, 20 คณะ/ฝ่าย, 250 รายการมอบหมาย (ไม่ซ้ำไม่สามารถสรุป), 236 รายการกีฬา; แสดงขอบเขตการจัดการและสถิติ 4 หมวดสูงสุด พร้อมจุดรอตรวจรับ. ห้ามแสดงจำนวนกรรมการรับรอง/โรงเรียนตรวจแล้วเพราะไม่มีฐานยืนยัน.
4. คงเลขหน้า/สารบัญ/QR ที่เหลือ, กติกา/ประกาศ/บัญชีกรรมการในฐานเดิม; **ไม่ Merge PR #139, ไม่เปลี่ยน main/Pages/Sheets/JSON/ผลจริง**.
