# R52 — การปรับ PDF ตารางแข่งขันให้เป็นรูปแบบสูจิบัตร (18 พ.ย. 2569)

สถานะ: **ไฟล์ PDF ฉบับตรวจร่างสร้างและตรวจในบทสนทนาแล้ว / ยังไม่อัปโหลดเข้าที่เก็บเอกสารทางการ / ยังไม่ Merge / ยังไม่ตรวจรับโดยผู้จัด**

## คำสั่งผู้จัด
- ปรับ PDF ตารางแข่งขันล่าสุด R51 ให้ใช้ **ภาพหน้าปกสูจิบัตรเดิม** ที่ผู้จัดเลือกไว้
- เฉพาะตารางการแข่งขัน ไม่รวมผลแข่งขัน ตารางคะแนน กรรมการ หรือผังอื่น
- ทำต่อให้เสร็จโดยรักษาข้อมูลที่รับรองจาก R32/R33
