# R11C-V4.1 — รายงานการดำเนินงานและข้อจำกัด

วันที่: 6 พฤศจิกายน 2569 · สถานะ: V4.1 preview (ไม่ใช่สูจิบัตรประกาศใช้)

## สิ่งที่ต่อยอดจาก V4

1. **หมวดประกาศ** เป็นหน้าเอกสารทางการกึ่งหนังสือราชการ ใช้ Sarabun (Google Fonts / มีหัว) ฝังใน PDF เมื่อ font โหลดสำเร็จ; fallback เป็น Noto Sans Thai Looped. TH Sarabun New สามารถใช้แทนเมื่อมีไฟล์และการอนุญาตเหมาะสม. Sarabun Google Fonts ไม่ใช่ไฟล์ TH Sarabun New เดียวกัน.
2. **พิธีเปิด/ปิด** timeline แสดงเฉพาะเวลาใน V3 หน้า 3/4; ข้อความช่วงไม่มีเวลายังอยู่ในช่วงที่มีเวลาสุดท้าย ไม่แต่งเหตุการณ์/เวลา
3. **สีโรงเรียน/คำปฏิญาณ** แสดง 8 การ์ดกับบล็อกคำปฏิญาณอ้างอิง V3 หน้า 5; swatch เป็นการออกแบบโดยประมาณ ต้องให้โรงเรียนยืนยันเฉดและข้อความก่อนใช้
4. **กีฬา/ประกบคู่** การ์ดคู่จาก `fixture.id`, สรุปรอบน็อกเอาต์เฉพาะรายการที่ระบุใน source; ไม่วาดสายแบบคาดเดา ไม่เพิ่มทีม/ผู้ชนะ
5. **หมวดท้ายตรวจเป็นพิเศษ** ใช้รายงาน R12A ที่มีอยู่ ไม่สร้าง engine ตรวจนักกีฬาซ้ำใน repo สาธารณะ คงข้อมูลเลข 33/96/53 ตาม snapshot เดิม **237 candidate events** และระบุชัดว่ายังไม่ใช่ conflict รายคน

## ยังต้องตรวจรับก่อนเผยแพร่

- ตัดสินประเภทหน้าแรกว่าจะเป็น **ประกาศ** หรือ **คำสั่ง**; V3 หน้า 6 ใช้ “ประกาศ” แต่หน้า 16 ใช้ “สั่ง ณ วันที่”, ตรวจอำนาจลงนาม เลขที่ วัน ลงนาม และถ้อยคำ
- ยืนยันคำปฏิญาณนักกีฬาทีละคำ, ลำดับพิธีเปิด และสีโรงเรียนกับแหล่งทางการ
- ตรวจ V3 ภาคผนวกที่คงรูปเดิมซึ่งอาจมีรายการก่อนแก้ และข้อมูลตะกร้อคู่ 9
- ยืนยันเวลา/สนามย่อยเปตอง, กรีฑา 50 รายการที่ยังไม่มีเวลาเริ่มรายรายการ, 60 คู่ที่ยังไม่รู้ทีมครบ และรายการวันที่ผิดปี
- **รายชื่อเด็กจริง** ยังไม่อยู่ในพื้นที่ public และไม่มีการรับรองว่าไม่มีการชนกัน; ต้องใช้ R12B/C ในพื้นที่ private และตรวจตามโรงเรียน/รุ่น/กีฬา/เวลา/ช่วงรายงานตัว
- กรรมการตรวจรายการที่อาจต้องทำหน้าที่สองสนามพร้อมกัน; ต้องมีช่วงเวลาที่ตรวจรับ
- ตรวจภาพ PDF ที่ render จริงและพิมพ์ A4 100%; ไม่ใช่การรับรองเนื้อหาทางกฎหมายหรือโปรแกรมแข่ง

## ความปลอดภัย

ไม่มีการเปลี่ยน `program.html`, `committee.html`, `data/program-*.json`, `data/public-results.json` หรือ PDF V2/V3. Workflow สร้างและอัปโหลด artifact สำหรับอ่านตรวจเท่านั้น. ต้องผ่าน R11E Gate ก่อนเปลี่ยนบนเว็บไซต์.
