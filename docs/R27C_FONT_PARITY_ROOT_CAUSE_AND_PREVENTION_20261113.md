# R27-C — วิเคราะห์ฟอนต์หลุดและมาตรการป้องกันสูจิบัตร

13 พฤศจิกายน 2569 • **PLAN RECORDED / REVIEW PDFs BUILT / FONT PARITY QA PASS / DRIVE UPLOADED / PENDING ORGANIZER ACCEPTANCE / NOT MERGED / NOT WEBSITE PUBLISHED**

## เหตุที่ฟอนต์หลุด (Root cause)

1. การแก้ PDF ใน R27 รุ่นแรกใช้ภาพข้อความวางทับเพื่อรักษารูปลักษณ์เดิม. R27-B จึงเปลี่ยนบริเวณแก้เป็นข้อความที่ค้นหาและคัดลอกได้ แต่ใช้ **Waree / Waree-Bold เป็นฟอนต์รวม** โดยไม่ได้อ่านฟอนต์ของช่องใกล้เคียง.
2. แท้จริงแล้วฉบับ **41 หน้า** ใช้ **Noto Sans Thai Bold** (PDF เรียก Noto-Bold) สำหรับชื่อทีม. ส่วนฉบับ **155 หน้า** ใช้ **Noto Sans Thai Regular / Bold** (PDF เรียก NotoThai / Noto-Sans-Thai) ในตารางและผัง และ **Sarabun** (PDF เรียก FormalThai) สำหรับตัวเลขบางชุด. Waree ที่ใช้กับตัวเลข/สัญลักษณ์บางส่วนของเล่มเดิมเป็นองค์ประกอบตามต้นฉบับ **ไม่ควรลบ Waree ทั้งเล่ม**.
3. R27-B ตรวจจำนวนหน้า การมีฟอนต์ฝังและความถูกต้องของข้อความ แต่ **ไม่ได้มีกฎให้ฟอนต์ที่เพิ่มต้องตรงกับแถวเป้าหมาย**. ระหว่างแก้ R27-C ยังตรวจพบตัวสร้าง PDF บางวิธีเลือกฟอนต์สำรอง และบางวิธีเปลี่ยนสีเป็นดำโดยไม่ทำให้การสร้างไฟล์ล้มเหลว จึงต้องตรวจฟอนต์และสีจากไฟล์ PDF หลังสร้างจริง.
4. ในการจัดรูปภาษาไทย สระอำ U+0E33 บางวิธีสกัดข้อความผิด; R27-C ใช้การจัดรูป U+0E4D + U+0E32 ซึ่งแสดงและอ่านเหมือนกัน แล้วเปรียบเทียบ Unicode NFKC เพื่อป้องกันอักขระแปลกเมื่อคัดลอก.

## วิธีแก้และขอบเขต

ใช้ R27-B เป็นต้นทางและรักษาไฟล์เดิมทุกฉบับ แก้เฉพาะข้อความที่เพิ่มแล้วฟอนต์หลุด **23 จุดใน 10 หน้า**:

| ฉบับ | หน้าแก้ไข | รูปแบบที่ใช้ |
|---|---|---|
| 41 หน้า | 13, 15, 17 | Noto Sans Thai Bold ให้ตรงชื่อทีมและตาราง; ตัวเลข Waree เดิมคงตามแหล่ง |
| 155 หน้า | 61, 64, 69, 100, 102, 103, 138 | Noto Sans Thai Regular/Bold สำหรับรายการไทยและ Sarabun สำหรับเลขอ้างอิงที่ใช้ FormalThai |

รักษาสีตามแถวต้นฉบับ: #163653 (กรมท่า), #855A20 (น้ำตาลทอง), #55687D (ข้อความสถานะ) รวมถึงขนาดและตำแหน่ง. เลือก Pango/WeasyPrint เพื่อจัดสระและวรรณยุกต์ไทยด้วยฟอนต์จริงที่ฝังใน PDF.

**รายการที่ไม่เปลี่ยน:** เปตอง 10 ปีชายคู่ที่ 2 ยังคง รางขาม – ทุ่งมะสังฯ (12 พ.ย. 2569 เวลา 09.00 น. สนาม 2), คู่ที่ 10 ยังคงผู้ชนะคู่ที่ 3 พบผู้ชนะคู่ที่ 4, จำนวนรายการ 236, เวลา/สนาม/ผู้ชนะ/ผลแข่งขันไม่ได้เปลี่ยน และไม่แตะไฟล์ต้นฉบับที่ผูกพิกัดไฮไลต์บนเว็บ.

## หลักฐาน QA

- **PASS** 41/41 และ 155/155 หน้า A4 ขนาดและแนวหน้าเดิม.
- **PASS** ข้อความที่อยู่นอกขอบเขตใน 38 หน้า (เล่ม 41) และ 148 หน้า (เล่ม 155) ตรง R27-B ทุกหน้า.
- **PASS** ตรวจฟอนต์จริงจากข้อมูลที่ฝังใน PDF และจากชื่อ PostScript ของฟอนต์: Noto Sans Thai / Sarabun ตามตำแหน่ง, ไม่พบ Waree ที่เป็นข้อความไทยในหน้าแก้, ตรวจสี/ขนาด/ตำแหน่งครบ 23 จุด.
- **PASS** ข้อความใหม่สกัดได้เป็นภาษาไทย (ยอมรับรูป Unicode NFKC ที่เทียบเท่ากัน), ไม่มีข้อความแปลกของอักขระสระอำ, และภาพที่เปลี่ยนจาก R27-B อยู่เฉพาะบริเวณแก้ไข.
- **PASS** ตรวจภาพขยายของหน้าแก้ 13,15,17 (เล่ม 41) และ 61,64,69,100,102,103,138 (เล่ม 155); ตรวจอัปโหลดและอ่าน metadata กลับจาก Drive.
- **PENDING** พิมพ์ A4 เครื่องจริง, Safari/Chrome/LINE บนมือถือ, สิทธิ์เข้าถึงจากผู้ชมภายนอก และการตรวจรับจากผู้จัด.

## มาตรการป้องกันในทุกการแก้ไข PDF ครั้งถัดไป

1. **ก่อนแก้:** ระบุชื่อฟอนต์จริงของข้อความข้างเคียงในแถวเดียวกัน รวมถึงขนาด น้ำหนัก สี และกรอบบรรทัด. ห้ามเลือกฟอนต์เหมารวมทั้งเล่ม.
2. **ระหว่างแก้:** ใช้ไฟล์ฟอนต์ตระกูลเดียวกับต้นฉบับ รองรับการจัดรูปภาษาไทย และเก็บข้อความให้ค้นหาและคัดลอกได้; อย่าปรับข้อความอื่นเพื่อให้ดูเข้ากันโดยไม่ได้รับรอง.
3. **หลังแก้:** ใช้ตัวตรวจแบบ **FAIL CLOSED**: ถ้าฟอนต์จริง สี ขนาด การคัดลอกข้อความ จำนวนหน้า หรือพิกเซลนอกกรอบแตกต่าง ต้องหยุดก่อนอัปโหลด/เผยแพร่. ต้องไม่อนุมัติจากเพียงภาพที่เปิดได้หรือการมีฟอนต์ฝัง.
4. **ตรวจด้วยสายตา:** เปรียบก่อน/หลังเฉพาะข้อความที่แก้และแถวข้างเคียงทุกกรอบ; ทดสอบพิมพ์ A4 และมือถือ/LINE จริงเมื่อจะเผยแพร่.
5. **จัดการรุ่น:** ร่าง → QA ผ่าน → ส่งผู้จัดตรวจรับ → อนุญาต Merge → เผยแพร่และตรวจจริง; เก็บต้นฉบับทุกรุ่น ไม่เขียนทับหลักฐาน.
