# R11C-V4 Phase 1 — ตรวจโครงสร้างและแหล่งข้อมูล

ตรวจวันที่ 6 พฤศจิกายน 2569 · อ้างอิง R11C เดิม ไม่ใช่โครงการสร้างระบบเอกสารใหม่

## สถานะ
- ข้อมูลใน Google Docs working copy อ้างอิง PDF V3; พบ **64 ข้อความ marker** `【หน้า NN / 64】`
- Google Docs ใช้ **1,953 paragraphs, 0 native tables, 0 explicit page breaks**. หมายเลข marker **ไม่ใช่** การแบ่งหน้า native ของ Docs และไม่ใช่ตำแหน่งหน้า V4 ที่จะสร้าง
- สร้างแผนที่เนื้อหาใน `data/souvenir-v4/source-outline-v1.json` รวม 64 รายการ และ sample contract 6 รูปแบบ `data/souvenir-v4/sample-page-contracts-v1.json`
- หน้าที่ข้อความสำเนา Docs มีเนื้อหาน้อย: 1, 2, 61, 64 — ต้องตรวจภาพ PDF และองค์ประกอบกราฟิกก่อนตัดสินว่าเป็นหน้าว่างจริง (เช่น ปก V3)
- ข้อมูลบุคคล/ภาพ/รูปแบบตารางใน Docs เป็นข้อความที่ถอดมา ไม่ใช่ตารางที่ใช้ออกแบบหน้าพิมพ์ใหม่ได้เลย
- ชื่อหน้า/บทบาทหมวดเป็น **index สำหรับวางโครงสร้าง**; ไม่ใช้ทดแทนการตรวจหน้า PDF จริง

## งานที่มีอยู่แล้วและหลีกเลี่ยงการซ้ำ
- R11C working copy/Google Docs: นำกลับมาใช้เป็น editorial source; ไม่แก้ทับเอกสาร
- R11A candidate + R20 correction: ใช้ stable IDs และ approved planning fields; raw candidate 237, corrected view 236
- R19K พิกัด PDF V3: ไม่ดัดแปลง map 250 จุดให้ใช้กับ V4 โดยตรง; PDF V4 ต้องสร้างพิกัดใหม่จากไฟล์จริง
- R11D Reader/R11E Release: ไม่เปลี่ยน URL หรือ PDF ที่เว็บใช้งานใน Phase 1
- R20 Results/Sheets: ไม่แตะผลการแข่งขันหรือสิทธิ์

## ความเสี่ยงก่อนพิมพ์ V4
1. ฟุตบอลมัธยมหญิงชิง: V3 ยังมีรายการวันที่ 20 พ.ย. ซ้ำ; print snapshot ต้องใช้คำยืนยัน 18 พ.ย. รายการเดียวและเก็บหลักฐานเดิม
2. ตะกร้อคู่ที่ 9 บน V3 มีบรรทัดซ้ำ ต้องตรวจรหัสคู่ก่อน render
3. หน้า 2, 61 และ 64 ไม่มี body ตามข้อความถอด Docs; หน้า 1 เป็น placeholder ปก; อาจมีภาพ/องค์ประกอบที่ text extraction ไม่แสดง
4. พิกัดเลขหน้าจาก V2->V3->V4 ไม่ใช่ offset เดียวกัน, กรีฑามีการจัดหน้าแตกต่าง
5. ชื่อกรรมการ V3 ยังรอตรวจ; ห้ามเขียน "แต่งตั้งแล้ว" และต้องตรวจรายชื่อก่อนเผยแพร่
6. การยืนยันเวลาและสนามย่อยยังไม่ครบทุกคู่; ห้ามอัปเกรดจาก draft source เป็น approved โดยอัตโนมัติ
7. การจัด PDF A4 ต้องผ่าน visual QA และ print QA บน PDF จริง; CI ตรวจ schema ไม่ทดแทนการดูภาพ/พิมพ์

## Next Gate
