## เป้าหมาย
ครูทุกโรงเรียน 8 แห่งที่อยู่ใน catalog สามารถแชร์ข้อความรายวัน/ตามตัวกรอง, ทุกกีฬา 9 ชนิด, รายคู่+กรีฑารายการลู่ ได้จากหน้าตาราง โดยผู้รับอ่านข้อมูลทันทีใน LINE และกดลิงก์สั้นกลับไปยังตารางที่กรองตรงกัน

## ขอบเขตพัฒนา
1. เพิ่มปุ่ม 'แชร์ตารางที่เลือก' ใกล้ปุ่มอัปเดต และ 'แชร์วันนี้' รายวันที่แสดง ไม่ซ้ำปุ่มแชร์รายคู่บนการ์ด
2. ดูตัวอย่างข้อความก่อนแชร์ เลือกโรงเรียนปลายทางได้แม้หน้าจออยู่ 'ทุกโรงเรียน', รองรับภาพรวมทุกโรงเรียน พร้อมส่วนย่อยแบ่งตอนเมื่อรายการมาก
3. ข้อความไทยเรียงตามวัน/เวลา ครอบคลุมสนามหลัก, ชื่อกีฬา รุ่น เพศ, คู่แข่งขันหรือกรีฑาพร้อมลู่; ไม่เดาผู้ชนะ/รอบถัดไป/เวลา/สนาม และติดสถานะยังไม่รับรองตามแต่ละฟิลด์
4. ลิงก์ย่อภายใน GitHub Pages `/t/?s=...&d=YYMMDD&g=...&l=...&r=...` → `index.html` และโหลดข้อมูลใหม่; ตรวจค่าที่รับจาก URL กับ catalog และวันจริงก่อนใช้
5. แชร์รวมข้อความ+ลิงก์ใน `text` ช่องเดียว รองรับ Web Share และ fallback คัดลอก, หลีกเลี่ยงอ้างว่า LINE ส่งสำเร็จเมื่อเพียงเปิดหน้าต่างแชร์
6. ยึด predicate R38 approved-only live สำหรับโหมด 'ยังไม่มีผล' แต่ถ้าตรวจ live ไม่ได้ให้แจ้งและไม่ซ่อนรายการผิด; การแชร์ต้องใช้ชุดรายการทั้งหมด ไม่ใช่ 12/8 การ์ดที่แสดง
7. เพิ่ม workflow/test ครอบคลุม 8 โรงเรียน 9 กีฬา, กรีฑา, วันกรอง, ข้ามวัน, หลายตอน, ค่าผิดปกติ, ยังไม่รับรอง, คงลิงก์เก่าและผล R32

- Short route เป็นเส้นทางสั้นของเว็บไซต์เดิม ไม่ใช่โดเมนใหม่; ลิงก์สั้นและข้อความที่ส่งแล้วไม่เปลี่ยนย้อนหลัง แต่หน้าเว็บโหลดข้อมูลปัจจุบัน
- โค้ดที่ Merge ไม่เท่ากับ Deploy; ต้องตรวจ GitHub Actions/Pages และ Safari iPhone, Android Chrome, LINE in-app browser/PWA เครื่องจริงก่อนประกาศตรวจรับสมบูรณ์
